Notes Rules you can't see on the page
Who ever sees this page
Anonymous visitors only — and that is new. Today GET / never reads c.var.auth: it renders the same page for everyone, signed in or not. The handler has to gain an auth check that sends organisers and reviewers to /admin and speakers to /portal. What already exists sits on /admin, which bounces anonymous users to /login and speakers to /portal. Neither of those fires on /.
Which events are listed
{{ r.mark }}
{{ r.what }} {{ r.why }}
The test is one question: would you mind a competitor reading it? GET / has no auth, so every listed event is world-readable.
Why three groups, not one list
A published programme stays published after the event ends, so a finished event would sit at the top of a flat list forever. Grouping fixes that and matches what a visitor arrived to find out: can I submit, or what's on? Within a group: soonest deadline first, then soonest event. Past events run newest first.
Kept off every row, deliberately
{{ x.name }}
Each of these describes how well an event is going, not what a visitor can do about it. A thin CFP or a stalled review wave is the organiser's business.
Three states, both widths
Each state is drawn at 900 and at 390, so there is no guessing which layout is being specified. Desktop lays an event out as a three-column row — dates, name and state, action. Phone stacks the same fields into a card with a full-width button. A published programme stays published, so once an org has run one event the hub always has something to show. Nothing here yet is a fresh deploy only. Between cycles is the common one — no open CFP, nothing upcoming — and there the archive leads the page rather than sitting under two empty headings.
Whose name is in the masthead
The org's, not the product's — matching the public event pages, which lead with the event name. One org per deployment, so the hub is simply "our events" and needs no org switcher. Chautauqua is named once, in the footer, as an attribution link to the repository. That is the only place the product appears on a customer-facing surface.
Two things this mock fudges
The seed holds one event. The autumn-workshops and 2026 rows exist to show what the shape does with several — they are not seeded data. The CFP date reads 16 August to match the rest of the set. The seed says 1 Mar 2027; reconciling that is still an open decision.
