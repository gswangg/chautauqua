Submissions

The chrome a page can draw without data — header, title, toolbar — is drawn immediately. Only the rows wait, and they wait as blocks at the row height they will become, so nothing jumps when the data lands.
RefTitleSpeakersStatusSent
Six rows, always — a skeleton that guesses the real count lies twice: once while loading, once when the number differs.
The rules Under 250ms, show nothing — a skeleton that flashes is worse than a beat of stillness. Blocks never shimmer or pulse: an animation on a whole table is motion the user cannot act on, and it competes with the content arriving. The skeleton uses #EFEBDF, the same tone as a hovered row, so it reads as furniture rather than as content that failed to load.
