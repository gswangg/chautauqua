There is no sign-in-as path anywhere in this product, so the tooltip instructs an organiser to perform something impossible. RULED: a tooltip is copy. The vocabulary rule reaches title/aria-label/placeholder exactly as it reaches visible text, and it gets a sentinel rather than a one-line edit, because a ruling with no gate drifts back. The sentinel must be boundary-aware — "They can sign in as soon as you do this" (PeopleRolesPanel) and "signed in as {email}" (a true statement about the viewer's OWN session) are legal and each gets a negative control.
