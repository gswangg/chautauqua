# DEC-851: D21 amendment: the client half never lands alone — apiGetCached/apiListCached/useCachedRead and their first page reader (contacts) are one commit

This is the reason D21 was scheduled as a subsystem rather than a task. A cache in api.ts with no page reading it is precisely DEC-851's declared-knob-with-no-reader and DEC-988's setting-with-no-reader: the capability would be real, tested, and invisible, and "a page will adopt it next wave" is how this codebase acquired the shape both those decisions exist to name. RULED: task v12m-w4-t-r1-a carries the client contract AND the contacts adoption in one commit and is flagged integration, so the merge policy works hardest to land it whole; if any part of it must be dropped, the cache goes with it. The two remaining adoptions (submissions, speakers) and the cross-page guards depend on it only because they cannot compile against helpers that do not exist — not because they are less required. Contacts was chosen as the first reader on contention grounds: app/src/pages/contacts/ContactsApp.tsx is unowned by every unmerged v12m-* branch (v12m-w10-j owns the sibling ContactsTable.tsx, which DEC-678 was shaped to avoid touching), and its `/contacts?…` directory read is a plain single list with one already-surfacing catch. Speakers is deliberately LAST of the three: OnboardingGrid.tsx's loadGrid is awaited from eight imperative post-write call sites, which is why the hook result carries `refetch(): Promise<void>` at all.

## Amendment (wave 122): a campaign ceiling is either an exit gate or an excused one — "graded but never reported" is a third state that must not exist

`scripts/exit-predicate.ts` keeps two lists: `CAMPAIGN_CONSTANT_NAMES` (what `assertCampaignPopulationTotal` accounts for) and `TIER2_CEILING_NAMES` (what `buildCampaignReport` actually turns into rows and what `campaignDone` requires to read 0). `UNDECLARED_HEIGHT_OFFENDERS_CEILING` — the wave-120 lens for the second evasion mode DESIGN-RULINGS names for the 44px floor, currently at 23 — was added to the first list only, so it is never printed in the campaign table and never blocks DONE: a declared knob with no reader, exactly the lie DEC-851/DEC-988 name. RULED: (a) `UNDECLARED_HEIGHT_OFFENDERS_CEILING` joins `TIER2_CEILING_NAMES`, since the mandate's Tier 2 explicitly requires the 44px sweep to cover both evasion modes; (b) a new assertion makes the third state unrepresentable — every `CAMPAIGN_CONSTANT_NAMES` entry that is a ceiling (bare `CEILING` or `*_CEILING`, i.e. not one of the four ledger FLOOR/EXPECTED_* names) must appear in `TIER2_CEILING_NAMES` or in `OUT_OF_CAMPAIGN_SCOPE` with a principle, and the assertion names every offender when it throws.

## Amendment (wave 22): The live 390 admin gate must WRITE its offender roster — a measured count with no names cannot be drained

`scripts/render-sweep.ts`'s admin mobile pass is the campaign's only instrument that measures real geometry on real admin screens at 390x844, it is blocking (`ADMIN_MOBILE_PASS_BLOCKING = true`), and it gates on `ADMIN_MOBILE_INTERACTIVE_OFFENDERS_CEILING = 79` — seventy-nine live interactive controls below the 44px floor — while EVERY static Tier-2 tap-floor ceiling in `scripts/exit-predicate.ts` reads 0. The per-route offender detail exists at run time and is `console.log`'d and discarded; grep finds no roster of those 79 anywhere in the tree. That is this decision's declared-knob-with-no-reader shape inverted: a reader with no record. Nobody can fix 79 controls they cannot name, so the mandate's Tier-2 44px sweep is structurally blocked by the instrument's own output handling, not by the work. RULED: the gate writes its offender roster to a committed audit ledger on every run, deterministically ordered so re-runs diff cleanly, with the formatting done by a PURE function unit-tested over fabricated results (no worker ever boots a server for this — the roster is populated by the next verification-wave gate run). The ledger lands committed and explicitly UNPOPULATED, naming the last measured total and its sha, so the gap is visible in the tree rather than only in a scrollback nobody kept.
