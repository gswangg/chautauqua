# DEC-994: A cascade-blind phone verdict is closed by a load-bearing stylesheet read, never by a `.css` string the predicate happens to see

`app/src/phone-verdict-cascade-read.scan.test.ts`'s predicate is a bare substring test (`.css'` / `.css" anywhere in the source`), so a lane could drop the ceiling from 9 to 0 by adding a dead `const X = 'foo.css';` and the instrument could not tell.
