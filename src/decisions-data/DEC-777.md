## Amendment (wave 147): the portal placement grammar carries the session's shape, not only its slot

Four caption-residue rows are one gap. ## Amendment (wave 148): the portal home session card carries the session's SHAPE and the deliverable's STANDING, not only its slot and filename

The wave-147 amendment above ruled that portal placement grammar carries the session's shape; it was never implemented (`v12m-w22-*` branches sit at main with zero commits). This amendment settles the two open questions that ruling left: (a) the home SessionCard's meta line leads with the FORMAT clause, rendered through `sessionFormatLabel` from `src/lib/session-vocabulary.ts` — the same vocabulary the sibling `SubmissionRow` in the same file already uses, never a second label grammar (DEC-613); (b) the deliverable line gains the version number the detail page already computes via `getFileVersionNumber` and the review-standing clause the detail page already speaks verbatim (`src/routes/portal/index.tsx:544` 'Shared with the organisers'), shortened to the frame's 'with the organisers'. The filename STAYS — `Chautauqua Public and Portal.dc.html:445`'s 'Slides v3' is the pack's own fixture filename, not a kind vocabulary, and inventing a deliverable-kind label set for one caption would mint a second vocabulary for a fixture. Any clause whose input is null is dropped, never defaulted.
