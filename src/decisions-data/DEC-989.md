# DEC-989: No phone surface may declare a horizontal extent wider than the 390 viewport minus its gutters, and the probe enumerates the declarations that force one

The mandate's Tier-2 horizontal-overflow probe at 390 has never been built, and the wave-1 handoff already records the defect it would catch (.chq-table td:first/last-child's 16px inset stacking on .chq-main's gutter for every card-stacking table, fixed locally in comms and never globally). jsdom performs no layout, so "measure" here means what it means everywhere else in this repo -- page-measure.test.ts and shell-geometry.test.ts read the stylesheets' own declarations, because "jsdom does not evaluate an external stylesheet's layout". RULED: the probe reads the content budget from the shell's own phone gutter rule rather than hardcoding 390-minus-a-guess, and flags four declaration shapes that force an extent beyond it -- px width/min-width/flex-basis above budget, grid-template-columns whose fixed tracks plus gaps exceed budget, white-space:nowrap on a rule declaring no overflow/text-overflow escape, and table-layout:fixed still in flow at phone with more than two columns. Population is enumerated from every app/src/**/*.css and src/**/*.css.ts (DEC-808), never a manifest. The ratchet is two-sided: an unlisted offender fails, and a structural exemption that no longer matches any rule fails with an explicit delete-this-line message (DEC-948's wave-49 shape). This is a phone rule; the desktop width system (three tokens, three classes) is unchanged.

## Amendment (wave 90): a phone overflow escape is PHONE-SCOPED — the 65 measured offenders are closed in the terminal max-width block, never by adding overflow:hidden to a base rule

w5-d's scan measured a 358px content budget (390 minus .chq-main's 16px phone gutter, derived from the shell rather than guessed) and recorded 65 offenders in files it could not edit. Its own four in-scope fixes added `overflow:hidden; text-overflow:ellipsis` alongside the existing `white-space:nowrap` IN THE BASE RULE — which is a desktop-affecting edit, and the campaign mandate freezes desktop (mobile-campaign.md:49-51). Left unruled, seven more lanes would copy that shape and quietly clip desktop labels that currently overflow visibly by design. RULED, three shapes, all inside the sheet's terminal `@media (max-width:700px)` block: (a) `white-space:nowrap` with no escape is re-declared at phone width with `overflow:hidden; text-overflow:ellipsis; min-width:0` — the `min-width:0` is not optional, a flex or grid child cannot ellipsis without it; (b) a `grid-template-columns` whose fixed tracks plus gaps exceed 358px re-lines to `1fr` (or `1fr auto` where a trailing control must keep its width) — a grid that cannot fit re-lines, per DEC-919's rule that a 390 frame keeps the desktop's capabilities and reaches them by re-lining rather than by removing; (c) a literal `width`/`min-width` above budget becomes `width:100%; min-width:0` unless the frame itself draws a scrolling matrix, in which case the container takes `overflow-x:auto` and the rule carries `/* overflow-exempt: <reason> */` naming the frame line that draws it. Truncation is never applied to a value that must stay exact (a token, a count, a reference); that case takes the exemption comment instead.

## Amendment (wave 93): a stale overflow-exempt comment is deleted the moment its rule stops being flagged

app/src/phone-horizontal-overflow.scan.test.ts's staleness half is red on main with three rows: agenda.css `.chq-agenda-clash-note` (:1445) and content.css `.chq-content-phone-select-toggle` (:1735) and `.chq-content-phone-selecting-all` (:1745). Each exempts a rule the scan no longer flags — the rule was fixed or re-shaped and the licence outlived it, which is the same failure mode as a ceiling above the truth: it licenses a future offender under that selector to arrive unseen. RULING: an exemption is a claim about a CURRENTLY flagged rule; when the rule stops being flagged the comment is deleted in the same change, and the deletion is the whole fix — never re-shape the CSS to keep the comment true.

## Amendment (wave 95): a ratchet ceiling is re-measured in the change that reads it, and an exemption over an empty rule body is a licence with no subject

ANCHOR_FLOOR_OFFENDERS_CEILING = 92 stands against 61 live offenders and OVERFLOW_OFFENDERS_CEILING = 65 against 24 — between them 72 phantom regressions licensed, carried unexamined across waves 90-94 because each wave read docs/design/audit/*.md (wave-6 snapshots) instead of running the scan's own function. A ceiling above the truth does not ratchet, it licenses. RULED: (a) a phone ratchet const is set to the count its own scan measures on the branch that touches the ratchet's inputs or its definition; a lane that touches neither never edits the const; a ceiling standing above the measured count is itself a defect and is filed like one, and its header comment must say it was measured by running the scan, not read from an audit doc. (b) An `overflow-exempt:` or `tap-floor-exempt:` comment must sit above a rule that ACTUALLY DECLARES the property it excuses. app/src/pages/content/content.css:1735-1749 carries two exemption comments over two EMPTY rule bodies (`.chq-content-phone-select-toggle {}` and `.chq-content-phone-selecting-all {}`) while the real `white-space:nowrap` rules three hundred lines above at :1425 and :1454 sit un-exempted and un-fixed — the licence and its subject came apart, which is why the staleness half is red and the offender half counts the same two selectors. An exemption over an empty body is deleted and the comment moves to the rule it was always about; re-shaping CSS to keep a stale comment true is never the fix.

## Amendment (wave 104): an overflow exemption follows its DECLARATION across a consolidation — move the marker onto the rule that declares the flagged property, delete it outright only when no rule declares it

Wave 93 ruled a stale `overflow-exempt:` comment is deleted the moment its rule stops being flagged, and wave 95 ruled an exemption over an empty rule body is a licence with no subject. Main today shows a third case neither covers, and the scan reports it as a contradiction: `.chq-content-phone-select-toggle` and `.chq-content-phone-selecting-all` appear BOTH in the 24-strong offender list AND in the 3-strong stale-exemption list. The cause is content.css's two phone blocks — the rules that actually declare `white-space: nowrap` live in the FIRST block (content.css:1425 and content.css:1454), while the second block (`:1737`, `:1748`) carries the `overflow-exempt:` receipts above EMPTY placeholder rules. The exemption is a property of the DECLARATION, not of the selector, so the marker never reached the declaration it was written for and both rules have been silently unexempted for as long as the second block has existed. Ruling: when a consolidation merges the blocks, the marker moves onto the rule that declares the flagged property and the empty placeholder is deleted; the marker is deleted outright only when no rule in the sheet declares the flagged property for that selector — which is the `agenda.css` case, where `.chq-agenda-clash-note` declares `white-space: normal` (the fix, not the offence) and the `overflow-exempt:` token must go while its prose may stay as a plain comment. Closing all three drops the overflow offender count 24 → 22 and takes the stale-exemption test to green.

## Amendment (wave 105): a phone overflow escape must change what 390 actually renders; wrap for prose, ellipsis for identity, and stacking is restated in the 700 layer

The DEC-989 scan clears a top-level offender the moment ANY phone-scoped rule carries the same selector token (`isCandidate` is false once the token appears in `phoneSelectorParts`). That is a live evasion: a lane could add `.chq-review-plan-actions { }` inside the phone block, watch the offender count fall, and leave a `white-space: nowrap` inherited from the desktop rule pushing the page past 358px at 390. RULED: the phone-layer closure must change the rendered outcome. For a `white-space: nowrap` offender the phone rule declares EITHER `white-space: normal` (prose, captions, labels, action clusters -- the text wraps) OR `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;` (single-token identity: a person's name, a filename, a file size, a count -- truncation beats reflow), and where the truncating element is a flex child its parent gets `min-width: 0` in the same block or the ellipsis never fires. Choosing per selector is the worker's judgement, but a phone rule that re-mentions the selector without resolving the nowrap is banned and must be treated as a failed fix even when the scan goes quiet. For a fixed-track `grid-template-columns` offender the phone rule stacks (`grid-template-columns: 1fr`) INSIDE the terminal 700px block even when a wider tablet layer already stacks it -- `.chq-review-plan-row` has stacked at `@media (max-width: 900px)` (review.css:136) since before the campaign and is still counted, correctly: DEC-385 single-direction reads the phone contract from the terminal 700 block alone, and a tablet layer is not a phone receipt. Measured population this wave: 24 offenders against a stale OVERFLOW_OFFENDERS_CEILING of 65.
