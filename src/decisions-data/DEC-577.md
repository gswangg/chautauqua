# DEC-577: Native controls are styled once in the shell lane; converting a select into a segmented control is per-page markup and stays with that page's redesign

## Amendment (wave 116): every control-class rule that sets a type register declares its family — CEILING goes 28 to 0

font-family is not inherited into <button>/<input>/<select>/<textarea> by any UA. app/src/control-font.scan.test.ts enumerates every chq- token applied to such an element and flags each CSS rule that sets font-size or font-weight without font-family; measured (ceiling forced to -1, twice, on clean archives of two different mains) the count is exactly 28, and the ratchet is two-sided, so 28 is truth and not a stale snapshot. Every one of those 28 controls computes the UA default face beside its Figtree/Familjen Grotesk neighbours the moment nothing upstream supplies one — the v12 frames draw the house faces on every control they draw, so this is frame divergence, not hygiene. The repair is the idiom the shell already ships (app/src/styles.css:599 `.chq-btn-tertiary { font-family: inherit; }`): one declaration per rule, additive, no reflow, no line inserted above any cited coordinate. RULED: the drain is one lane and one commit so a single owner moves CEILING to 0 — splitting it by cluster would put four lanes on one two-sided constant whose only correct value is a re-measurement.
