## Amendment (wave 16): the Overview section labels are a WIDTH decision, carried by the desktop/phone sibling-span idiom, never a second component

docs/design/Chautauqua Overview.dc.html's 390 frame draws four section labels that exist ONLY at phone — `01 — Overdue tasks` (:211), `02 — Awaiting triage` (:235), `03 — Content to decide` (:253), `04 — Agenda` (:270) — against the 1600 frame's longer forms at :74/:98/:117/:136. app/src/pages/Overview.tsx and overview/AgendaWorkSection.tsx render the desktop-length strings at every width, so the phone frame's own copy never appears. Overview has no isPhone split and DEC-919's own scan forbids a hidden control with no offset, but a section LABEL is not a control: nothing is unreachable when one of two labels for the same section is not painted. RULED: each label becomes two sibling spans on the existing `.chq-overview-section-label` — a `-desktop` span and a `-phone` span — with the phone span declared `display:none` in the sheet's normal cascade and revealed inside overview.css's single terminal `@media (max-width: 700px)` block, where the desktop span is hidden. This is the same shape `.chq-comms-batch-toggle-label-desktop`/`-phone` (DEC-833) and `.chq-detail-back-full`/`-short` already ship; no page-level phone fork, no `useIsPhone`, and the section's accessible structure is unchanged at both widths.
