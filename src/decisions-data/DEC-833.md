# DEC-833: A send is auditable to its words: the organiser can read exactly what a recipient received

## Amendment (wave 129): The send-history row's recipients disclosure carries the frame's 390 copy; the open state keeps the app's word because the frame draws no open state

Chautauqua Comms.dc.html prints `Open` on the desktop history row (:162, :644) and `See the recipients` on the 390 Send-history row (:350) — width-conditioned copy of the same control, the same shape as Wait/Waitlist. RecentSends.tsx already gives the control the frame's face (a bordered secondary at the tap floor); only the word is generic, and `Open` alone next to a subject line and a template name does not say which of the three it opens. So the closed-state label at <=700px becomes the frame's, desktop keeps `Open` byte-identically, and the OPEN state keeps the app's existing `Close` — the pack draws no expanded state here and inventing `Hide the recipients` to pair with it would be manufacturing copy the frame never printed, the same error DEC-576 wave-110 forbids for controls.
