# DEC-995: A ruling that PARAPHRASES a frame's geometry is corrected by ADDING the frame's numbers beside the paraphrase, never by replacing them

`docs/design/DESIGN-RULINGS.md:191` restates the Review results grid as `44px 1fr 150px 130px 92px 92px auto`; `Chautauqua Review.dc.html:124` draws `44px 1fr 132px 118px 190px 84px auto`; `review.css` carries a third set on user-filed gate-9 fits. DEC-902 wave-12m ruled the frame wins, and the field guide has flagged the uncorrected paraphrase for three waves — but the obvious repair is a trap: 13 citations point at `:191` and several QUOTE the old literal (`src/decisions-data/DEC-902.md`, `docs/design/audit/review-reviewer-desktop-v12.md`), and both files sit in populations whose unresolved-citation ceilings are 0. Deleting the old numbers would turn one stale paraphrase into several red citations. RULED: line 191 is edited IN PLACE, on one line, keeping the file's line count and keeping the old literal verbatim inside a clause that marks it as the superseded paraphrase, with the frame's own track set stated first and named as the authority (DEC-902 wave-12m). Every existing quote still resolves at `:191`; no downstream file needs touching. Generalises: a paraphrase's literal is load-bearing for whoever cited it, so a correction is additive and self-marking, never a substitution.
