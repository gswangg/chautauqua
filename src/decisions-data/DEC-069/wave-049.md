## Amendment (wave 49): an OUT_OF_CAMPAIGN_SCOPE excuse whose premise is a claim about its population is falsified the moment every row in that population is ruled LEFT

Measured at main 405a4518b: every non-zero *_CEILING in the tree except the three gating rows is excused by an OUT_OF_CAMPAIGN_SCOPE entry (47 of them). Two of those excuses assert their population is a defect count, and both assertions are false against the tree. PACK_UNIT_GRAMMAR_OFFENDERS_CEILING=6 is excused as "a real conformance fact ... promoted once a later lane drains it", but src/decisions-data/DEC-937.md's own wave-35 amendment already rules all six LEFT ("all 6 gap offenders are LEFT (5 by this amendment, 1 ... DEC-989 wave-42)"), each site carries an in-code receipt naming the competing ruling, and three passing test files pin the exact values byte-for-byte -- the population can NEVER be drained by repair, because repairing it would break the ruling that requires it. DRAWN_FIELD_LABEL_DIVERGENCE_CEILING=2 is excused as "a real, standing divergence", but both rows are the same Settings "Public URL" vs "Slug" field blessed in DEVIATIONS.md §7 and re-recorded in the ledger's own audit doc as "blessed, recorded divergence ... LEFT ALONE". The exit predicate's own machinery already knows what to do: PARKED_FIDELITY_PROMISES + assertParkedPromisesAreHonestlyParked throw both when a promise has no rule behind it AND when a promise's live evidence clears both clauses while its ceiling still sits parked. What is missing is the disposition every sibling ledger already has (SETTLED / FIXTURE / COMPOSED tables with per-row resolve-checks). RULED: (a) an OUT_OF_CAMPAIGN_SCOPE reason that makes a factual claim about its rows is re-derived against the tree before it is inherited, exactly like a ratchet value; (b) where every row of a parked ceiling resolves to a standing ruling or a DEVIATIONS blessing, the instrument gains a cited, per-row exclusion table whose rows are checked to still resolve in the pack and in the source, the ceiling falls to 0 by CLASSIFICATION not by repair, and the constant is moved out of OUT_OF_CAMPAIGN_SCOPE into CAMPAIGN_CONSTANT_NAMES + TIER2_CEILING_NAMES in the same commit, its PARKED_FIDELITY_PROMISES row deleted with it; (c) an exclusion row is only legal when it cites the ruling or DEVIATIONS section that requires the value AND a resolve-check proves the cited coordinate still declares it -- a bare "adjudicated" string is the allowlist shape DEC-725 already forbids.
