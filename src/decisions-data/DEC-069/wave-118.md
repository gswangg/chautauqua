## Amendment (wave 118): the campaign exit predicate's ratchet population must be TOTAL — every campaign ceiling is graded or carries a principle-shaped out-of-scope reason

`scripts/exit-predicate.ts`'s `CAMPAIGN_CONSTANT_NAMES` is a hand-listed population of 12 names — precisely the shape DEC-180/DEC-808 forbid ("a hand-listed population is not a population"). Measured against the tree there are 17 `*_CEILING`/`*_FLOOR` constants plus control-font's bare `CEILING`; NINE are ungraded, and one of them is `MARKUP_PHONE_UNHIDDEN_CEILING = 34` — thirty-four markup-mounted phone classes with no top-level `display:none`, i.e. phone affordances painting on desktop. `DIVERGENCE_CEILING` (the mandate's own Tier-2 density-pairing sweep) is ungraded too. As it stands the machine can print `CAMPAIGN: DONE` while the campaign's own instruments are red, which converts the exit predicate into decoration — the exact failure wave 115 named when a train landed over a live ratchet. RULED: the predicate derives the candidate set mechanically from the campaign scan files' source text and asserts totality — every derived constant is either GRADED (counted toward desktop/phone/Tier-2) or named in an exported `OUT_OF_CAMPAIGN_SCOPE` map whose value is a PRINCIPLE (a fact about the code that survives every branch name and wave number being deleted, per DEC-099's shape), never a schedule. A constant that is neither fails the predicate loudly.
