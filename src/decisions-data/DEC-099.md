# DEC-099: A recorded DIVERGES row is a standing exemption from the campaign's exit predicate and must be counted by a two-sided ratchet, not merely narrated

The campaign owns two saturated coverage ledgers — phone `CLAIMED_FLOOR` 53/53 and desktop `CLAIMED_FLOOR` 100/100 — and both measure only whether a frame is CLAIMED, never whether it CONFORMS. Meanwhile ~50 audit files carry `DIVERGES` tokens whose truth decays silently: this pass alone found agenda-390's two rows and review-v12's `:964` row all satisfied by the tree while still reading as open.
