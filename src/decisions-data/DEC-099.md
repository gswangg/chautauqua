# DEC-099: wave-14m: the open-divergence ledger's grammar -- a negative-result or narration row is adjudicated by citation, and a summary-table row is atomic and carries its own

Re-measured live on b56101594: 101 audit files, 153 marker rows, 90 OPEN (the ledger's own constants still read 100/203/133, and shapes 15/38/27/73 against a pinned 18/57/38/90 -- every population constant in test/open-divergence-ledger.scan.test.ts is stale; v12m-w13-xa owns that file and re-baselines it). Triaging all 90 by hand: roughly 18 are lines that record the ABSENCE of a divergence ('## No DIVERGES rows filed', 'None. Both frames verify MATCHES end to end') or narrate a row a prior wave already retired; roughly 28 are `| :NNN Frame | ... |` summary rows whose governing ruling is written in the section directly above them but which the ledger's TABLE-ROW shape -- atomic by design, because a markdown table row is one line -- can never see. RULED, in two clauses. (1) A marker occurrence that records the absence of a divergence, or narrates one already closed, is adjudicated by citing THIS ruling in its own paragraph, stating which it is. The marker token is NEVER deleted to lower the count and no row is re-verdicted to make it disappear -- the corpus is append-only and a curated exclusion list would make the population hand-listed again (DEC-180/DEC-808). (2) A summary-table row states its own authority in-cell, naming the SAME ruling its section carries; a summary citing a different ruling than its section is a defect, and a summary with no citation is an OPEN row no matter how well-argued the section above it is. Corollary binding on every adjudication lane: new prose must never spell the eight-letter marker (that would add rows to the population it is draining), and no lane may add or remove a file under docs/design/audit/.
