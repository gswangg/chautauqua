## Amendment (wave 43): a frame-verdict render pin that queries the DOM after an await must use an async query — a load-order-dependent pin proves nothing about the frame

At main 3ae9bd5bf the fast tier is fully green (1406 files / 18,181 tests, 0 red) and `vitest run 390 phone Phone` is fully green (186 files / 2102 tests, 0 red), yet `vitest run frame-verdicts.render frame390.render` reads 1 file / 1 test RED: app/src/pages/Comms.frame-verdicts.render.test.tsx's "frame :286 Templates · 390" verdict. ## Amendment (wave 45): a verdict that is a TIMEOUT is not a verdict — memoize the corpus walk, never re-walk per graded name

MEASURED at main 796715738: `test/campaign-scope-registry-partition.scan.test.ts`'s single gating `it` and `test/frame-conditional-state.scan.test.ts`'s non-vacuity control BOTH fail with `Test timed out in 5000ms`, not with an offender list. `resolveLiveValue(REPO_ROOT, name)` runs `git ls-files -- test app/src scripts` and then reads EVERY returned `.ts` file — once per promise-bearing name (7 today, growing every wave a ratchet is registered). The instrument therefore gets slower exactly as the registry it grades grows, and the first thing it loses is its own verdict. DEC-976 wave-43 already ruled "a pin that is green alone and red under load is worse than a green pin memorializing a gap"; this is the mirror case — a pin that is RED under load and would be GREEN alone tells the planner nothing about the registry. RULED: (a) an instrument that resolves N names out of one corpus reads the corpus ONCE, at module scope, into a `Map<name, {value, path}>`; per-name resolution is a map lookup and never touches the filesystem. (b) The same applies to any grader whose per-row cost includes a corpus load — `gradeRow` in frame-conditional-state loads its cluster corpus per invocation. (c) Raising a test's `timeout` argument is NEVER the repair for this shape: it hides the growth curve instead of removing it, and the next registered ratchet re-breaks it. (d) Every instrument repaired under this clause must be shown green BOTH standalone and inside a run of >=40 files, because those are two different measurements (DEC-976 wave-43).
