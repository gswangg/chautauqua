# DEC-976: Amendment (wave 103): an unclaimable desktop frame stays UNCLAIMED — a claim test never weakens its assertion to what the tree already satisfies, and a divergence from a frozen desktop frame is filed as a finding

The desktop half is 16 of 102 and this wave puts six lanes on it simultaneously — the first time claims are written at scale. DEC-976 wave-101 fixed the SHAPE (one node-tier test file per cluster, expected values typed as literals) but not the STANDARD, and a claim is trivially cheap to fake: every frame can be "claimed" by asserting something the tree obviously satisfies, which would drive CLAIMED_FLOOR to 102 of 102 while proving nothing about conformance, and this ledger is the desktop half's only instrument. Desktop is FROZEN by the campaign mandate, so a claim lane cannot fix a divergence it finds even when the divergence is real. The honest output is therefore asymmetric: assert the frame's drawn value against the tree, and when the tree contradicts it, leave the frame unclaimed and write the divergence (frame line, drawn value, shipped value) into docs/design/audit/desktop-frame-ledger-v12.md for a later lane or a DEVIATIONS entry. The floor then measures conformance rather than effort, and an unclaimed frame is a scheduled task rather than a hidden defect.

## Amendment (wave 105): a desktop frame the tree contradicts stays UNCLAIMED, and its divergence is filed in the claiming test file's own header

38 of 102 desktop frames are unclaimed on main; wave 5 schedules 32 of them (v12m-w4-k holds the 6 Review frames). The pressure a claim ledger creates is to claim, and the honest outcome for several of these frames is a divergence, not a claim: DEVIATIONS.md §6 already defers `Chautauqua Settings.dc.html:1111` (Your-data edit view -- retention select, keeping-and-deleting checkboxes, revoke-every-token footer, unbuilt), the shared ConfirmDialog 480/subtitle/typed-label anatomy behind :1392/:1414, and the Sessionboard importer modal behind :1507. RULED: a frame whose drawn anatomy the tree does not carry stays unclaimed, and the divergence is filed in the header comment of the lane's OWN new test file -- never appended to DEVIATIONS.md (user-owned; a worker does not bless a deviation) and never to a shared docs/design/audit/*.md, which would put five parallel lanes on one file for no benefit. Correctness against the pack beats claim count, and an unclaimed frame with a written reason is worth more than a claim propped up by a weak assertion. Second half, binding on every citing `it()` this wave: the frame-receipt tautology guard sits at FRAME_RECEIPT_OFFENDER_CEILING 0 and v12m-w4-j is widening its population to read citations out of it()-BODY comments as well as titles. Every new `it()` must therefore carry (a) the strict citation, (b) a backtick-quoted literal copied verbatim from that frame line, and (c) at least one `expect()` whose subject textually resolves to a readFileSync of a path OUTSIDE docs/design or to a render/DOM query. An it() whose every expect() subject is a frame read is a receipt stapled to itself.


## Amendment (wave 106): a claim a DOCUMENT makes about the tree is a citation and must resolve; the decision registry is inside the scan's population, and an audit finding is re-derived before it is scheduled

The user filed an INTEGRITY item into docs/mobile-campaign.md on 2026-08-19 evening: 'src/decisions-data/DEC-986.md (scribe wave 10/11) documents phone-CFP fixes that DO NOT EXIST in the tree'. I verified it on main 114b4d2c -- DEC-986's body says 'Fixed (1) by calling reportValidity() ... Fixed (2) with querySelectorAll + forEach', and at that sha the Next handler still advanced with an unvalidated setStep while the visibility script still un-required with a singular querySelector. Both landed in wave 109; the receipts now read cfp-steps-script.tsx:77 `if (!control.checkValidity()) return control;` and form-render.tsx:283 `wrap.querySelectorAll`. DEC-976 already governs this class of defect for stylesheets and tests -- a citation must be followed by a verbatim backtick-quoted literal, and frame-citation.scan.test.ts enforces it -- but the decision registry itself, the document every other document defers to, is outside every scan's population. That is the same hole DEC-808 names as A DIRECTORY IS NOT A POPULATION, one level up. RULING (a): src/decisions-data/DEC-*.md joins the citation contract. Every `<repo-relative path>:<line>` a decision doc states must resolve to a file that exists and is at least that long, and every backtick-quoted literal that follows such a citation must appear verbatim in the cited file, enumerated by readdirSync and pinned by a vacuous-population tripwire. Unresolvable claims carry a shrink-only ratchet seeded at the measured truth, so a scribe can no longer write fiction into the one artefact nothing checks. RULING (b), the same rule read backwards: a finding recorded as OPEN in docs/design/audit/*.md is a claim about the tree with the same standing, and it is RE-DERIVED against main before a planner schedules it. Five of the open findings I read this wave were already built (speakers-v12.md §2 and §3, comms-drill-v12.md's three held items, review-admin-v12.md §3), and re-ploughing them is exactly the cost this rule exists to stop. A finding verified closed is rewritten as `## N. RESOLVED (wave 106, <path>:<line>) — <original title>`, the convention speakers-v12.md §1 already uses.

## Amendment (wave 107): a frame the design authority DEFERS is not an unclaimed frame — the desktop ledger gains a derived DEVIATION-DEFERRED exclusion class

MEASURED, not inherited: on a clean archive of main I projected the six in-flight desktop-claim lanes (v12m-w4-k Review, w5-a Settings, w5-b Settings dialogs, w5-c Portal, w5-d Overview/Home, w5-e Agenda/Content) and re-ran test/desktop-frame-ledger.scan.test.ts — it reaches 99 of 102, and exactly three frames survive. Two of them, `Chautauqua Settings.dc.html:1111` ("Settings · editing your data") and `:1507` ("Import from Sessionboard"), are ALREADY deferred by docs/design/DEVIATIONS.md §6 under a user ruling of 2026-08-16, and the two lanes that owned them (w5-a, w5-b) each wrote a divergence note explaining why they refused to force-fit a claim. So the desktop half of the campaign's own exit test is unreachable BY CONSTRUCTION: the ledger enumerates its population from the pack and has exclusion classes for template interpolations and explainer panels, but none for the third authority the mandate names. A ratchet whose ceiling no honest work can reach is not a gate — it is a permanent red with no owner, which is exactly the failure DEC-367 named for SHADOWED_CEILING. RULED: a desktop frame is excluded from the ledger's population when docs/design/DEVIATIONS.md defers it BY EXACT `docs/design/<file>.dc.html:<line>` CITATION inside §6. The exclusion is DERIVED from that file at test time, never hand-listed in the test (DEC-808), so adding one is a visible edit to the authority document under the user's own deferral section, not a quiet test edit. Four guards make it non-abusable: the pre-exclusion total (102) stays asserted so the population can never shrink by breaking the grammar; the excluded count is asserted EXACT so growth is loud; each excluded citation must resolve to a real frame LABEL line whose title appears verbatim in the bullet that cites it; and no excluded frame may be claimed by any test — an exclusion a claim has overtaken is stale and is deleted, never carried. The mirror image of the phone ledger's stale-floor companion (DEC-808 wave-85), applied to the population instead of the floor.

## Amendment (wave 109): A citation's receipt lands in the commit that writes the citation, and the ceiling drops to what the tree measures

main is red on two halves of one contract. `app/src/frame-citation.scan.test.ts` measures 4 unreceipted phone-frame citations against a ceiling of 2 and 29 unreceipted desktop-frame citations against a ceiling of 28 -- both went red because merges (v12m-w3-y, w4-l, w4-m) and a merge-train ceiling lowering landed in different commits than the citations they concern. One of the four phone offenders is the scan's OWN negative-control fixture at :594, whose string uses a REAL frame path (`Chautauqua Speakers.dc.html:261`), so the control joins the population it is meant to police -- the field guide's rule that a sentinel must never be anchored on a real artefact, applied to a synthetic. RULING: (a) a synthetic control cites a frame filename the pack does not contain, so it can never enter the population; (b) every citation carries, in the same comment, the cited line's literal declaration in backticks read verbatim out of the named frame file, with a real `expect(` within six lines beneath it; (c) both ceilings are lowered to the value the scan measures after the fix, in the same commit -- a ceiling left above the truth is an instrument that cannot fail.

## Amendment (wave 110): the decision-registry citation ceiling is spent, not carried -- 29 of 29 with zero slack means the next drift is invisible

test/decision-doc-citation.scan.test.ts's UNRESOLVED_CITATION_CEILING is 29 and the measured truth is exactly 29: the ratchet is saturated, so any new broken citation fails the build only after a merge has already made one MORE break. Two were repaired by a merge train this wave and the ceiling followed them down, which is the mechanism working -- but 29 remain, seven of them paths that no longer exist (moved components) rather than line drift. RULED: a lane repairs every citation that can be resolved against the tree and lowers the ceiling to the count it MEASURES after its own repairs (force the const to -1 and read the offender list; never copy a number from a report). A citation whose target genuinely moved is repointed at the file's current content, not deleted -- deleting the citation loses the receipt, which is the thing DEC-976 exists to protect.

## Amendment (wave 112): a citation's line number is a coordinate, and the quote is the thing that must be true

Three of this wave's frame-citation failures are pure coordinate drift against quotes that are still correct: the public agenda dock band is at Public and Portal.dc.html:400 (cited 399), the my-schedule dock at :884 (cited 885), and Submissions.dc.html's `display:flex; gap:7px; overflow-x:auto` at :148 (cited 137). The pack was not re-cut; the citations were written against the section's opening line rather than the line carrying the literal. RULED: a frame citation names the line the quoted literal actually occupies (a range may follow, but its FIRST line is the one the scan reads), and a repair re-locates the quote by grepping for it rather than adjusting the quote to whatever the stale line now says. Same rule governs the decision-registry and widened-audit-doc repairs: re-point the coordinate, never soften the claim.

## Amendment (wave 113): A widened-population citation is repaired by re-pointing the coordinate to the line that carries the literal — never by softening or deleting the quote

43 unresolved rows against a ceiling of 42. 27 live in docs/design/audit/phone-tap-floor-links.md (owned by v12m-w8-f); the other 16 are spread over ten campaign authority documents and are almost all the same shape — the citation names a section's opening line, or a line that a later edit moved, while the backtick quote beside it is still true somewhere in the file. RULED: the repair is to grep the named file for the quoted text and rewrite the coordinate to the line that actually carries it. Deleting the quote to make the row pass is forbidden: the quote is the receipt and a citation without one is the very thing this scan exists to catch (DEC-967, 'a citation is not an assertion'). Where the quote is genuinely wrong about the file — the cited construct was deleted or renamed — the row is repaired by rewriting BOTH the coordinate and the quote to what the file now says, and the audit prose around it must be corrected in the same edit, never left contradicting its own citation. One row (`phone-tap-floor-links.md`, `PlanList.tsx:478` against a 337-line file) has no target at all and belongs to w8-f's document, not to this wave.
