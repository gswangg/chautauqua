The header-block exemption exists so a file's scope-naming citation need not carry its own receipt; the pay-for-it count is the exemption's price, and a file that declares scope over a frame while proving nothing about it is exactly the citation-not-conformance defect `UNRECEIPTED_CLAIM_CEILING`/`DESKTOP_UNRECEIPTED_CLAIM_CEILING` already gate at 0. Excusing it would let the exemption launder the two ceilings it sits beside. Registration also obliges a BELOW-direction companion `it` per `test/campaign-ratchet-two-sided.scan.test.ts`; the companion lands in the same commit as the registration, never after. ## Amendment (wave 17): a receipt-drain lane lowers a shared ratchet only to the value it can measure in its OWN worktree — driving a constant to the batch's post-merge truth is the merge train's job

The two header-scope ceilings measure 10 (phone) and 1 (desktop) on `aa18c504e` against declared 22 and 2, and eleven offender FILES are split across four clusters that must run in parallel to fit the wave. If every lane lowers the constant to the batch's expected end state (0), each lane's own targeted run is red for reasons outside its scope and a lane that fails to land leaves a ceiling below the truth — a ratchet pointing at a number nothing measures. If instead every lane lowers by its own count, four lanes collide on one line. RULED, two clauses. (a) SINGLE OWNER PER CONSTANT: exactly one lane in a batch edits a given ratchet constant; the other lanes in the same drain add receipts only and touch no ceiling. (b) MEASURE-WHAT-YOU-LAND: the owning lane sets the constant to the value the scan reports in its own worktree AFTER its own change (forced to `-1` to read the offender list), never to the value the batch is expected to reach. The residual gap between that number and 0 is closed by the merge train re-running the scan at `-1` after the batch lands — the same reconciliation `ceiling.ts`'s own history records, and the same one the wave-17 medic performed for `OPEN_DIVERGENCE_CEILING` (90 -> 4) when no lane owned the re-baseline.
