# DEC-385: Amendment (wave 103): a shadow can be load-bearing — a newly-winning phone declaration the frame contradicts is DELETED with the frame line as its receipt, never kept and never re-shadowed

DEC-385 wave-102 already rules that consolidation merges in ascending source order and that "a rule whose meaning changes under the merge is a finding, never a silent edit" — but it never says what the lane DOES with the finding, and this wave merges the four heavy sheets (review.css 11 blocks, styles.css 5, submissions.css 4, detail.css 3) that were deferred precisely because they are the risky ones. Consolidation moves every phone rule after every desktop rule, so a declaration that only ever slept because a later top-level rule beat it starts winning at 390 the moment the wrapper is deleted. Three outcomes exist and two are wrong: keeping it ships a 390 behaviour change no frame asked for, and re-introducing a shadow to suppress it re-creates the exact silent-cascade defect the one-block contract exists to kill. Deleting the declaration and citing the frame line that contradicts it is the only outcome that leaves the sheet single-valued and the removal auditable. Measured basis: all four heavy sheets already END in a phone block, so the fix is a pure forward-merge and every behaviour delta is attributable to a specific unshadowed declaration.

Same reasoning generalises — the consolidation edit may only ever move phone-layer bytes.

## Amendment (wave 27): single-direction responsive is defeated by any LATER equal-specificity rule, not only by an identical selector

The mandate's own cascade rule — filed after two lanes hit it independently — reads: "a stylesheet whose desktop rules are declared AFTER its max-width block silently kills equal-specificity phone overrides ... sweep the remaining stylesheets for the same exposure." `test/phone-cascade-order.scan.test.ts` was built to be that sweep and its population is honestly enumerated (43 files, a proven superset of the copy it replaced), but its RULE flags a phone declaration only when the SAME selector re-declares the SAME property at top level afterwards. A top-level rule with a different-but-equal-specificity selector matching the same element wins just as completely and is invisible to it. SHADOWED_CEILING = 0 is therefore evidence about identical selectors, not about the exposure the ruling names — the same wrong-axis reading wave 26 found in the tap-floor family, where six ceilings read 0 while the ruled width half went unmeasured. RULED: a second detector over the same population flags a phone declaration when a later top-level rule sets the same property, shares a `chq-` class token on a real class boundary (reusing `selectorMentionsToken`, never a sixth copy), and has equal or higher specificity. It lands under its OWN constant seeded at the MEASURED count and registered in OUT_OF_CAMPAIGN_SCOPE with a principle; SHADOWED_CEILING stays 0, so an unproven technique cannot move the campaign's goalposts mid-convergence.

## Amendment (wave 28): the cascade-order scan grades equal-or-greater-specificity subject-subset shadowing, not identical selector strings

The mandate's own cascade rule reads 'a stylesheet whose desktop rules are declared AFTER its max-width block silently kills EQUAL-SPECIFICITY phone overrides'. test/phone-cascade-order.scan.test.ts implements a strictly narrower rule: it flags a pair only when the later top-level selector string is byte-identical to the narrow one. A differently-written selector that still matches every element the narrow rule matched, at equal or greater specificity, beats the phone override on source order and is invisible to the predicate — SHADOWED_CEILING = 0 is therefore evidence about selector STRINGS, not about cascade order. Measured on main at f4629d5a with the widened predicate: identical 0, widened 0, so this is hardening before a regression, not a drain. RULED: the offender rule becomes — same property, later top-level declaration, top-level selector a single compound with no combinator whose tokens are a SUBSET of the narrow selector's subject compound, and specificity >= the narrow selector's. Identical selectors satisfy this trivially, so the widened predicate is a strict superset and the ceiling stays 0.

## Amendment (wave 29): a 390 verdict lane MAY fix, but only inside the phone layer and only under four conditions

Prior waves produced verdict files that are MEASUREMENT ONLY (portal-v12.md's own header says so), which is why fourteen waves of green ledgers have not moved conformance. A verdict that finds a real divergence and then only writes it down defers the campaign forever. RULING: a lane that finds its frame diverging MAY land the fix in the same commit when all four hold — (1) the change lives in the sheet's TERMINAL `@media (max-width: 700px)` block or behind an existing `useIsPhone`/phone-only render branch; (2) no desktop byte changes and the cluster's desktop pins stay green under a targeted run; (3) the same new test covers the fix; (4) the fix touches only files the lane OWNS. Otherwise the lane records a DIVERGES row naming the frame line, the built truth, and the DEVIATIONS/ruling disposition, and reports it to the planner. Never a product change outside the owned file set, never a raise of any ceiling.

## Amendment (wave 30): a verdict lane may land its own fix only inside files it exclusively owns this wave; on a stylesheet another in-flight lane owns it files a DIVERGES row instead
