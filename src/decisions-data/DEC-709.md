# DEC-709: Locked criteria are not a dead end: 'Start a new wave' carries the frozen criteria into a new round, and the plan editor is a summary plus inline rows

A review plan whose criteria lock at close is not a terminal state — 'Start a new wave' seeds a fresh plan from the frozen criteria of the one it succeeds, and the plan editor itself renders as a summary head plus inline editable rows rather than a fresh form each time.

## Amendment (wave 148): the phone plan-editor head carries the plan's scope, close date and reviews-per-talk as one subtitle, composed from the fields already on the page

`Chautauqua Review.dc.html:598` (the 390 plan editor) draws 'AI Engineering · closes 30 Aug · 2 reviews per talk' under the plan-name H1. The recorded blocker is accurate — Opens/Closes/Reviews-per-talk are three separate editable form fields and no composing site joins them — but every input is already in `PlanEditor.tsx`'s own state (`plan.filters.trackIds` resolved against the loaded tracks, `plan.closeDate`, `plan.maxEvaluations`), so this is a caption whose every input is already on the screen, buildable rather than a data-model gap. Two constraints: it is PHONE-ONLY (via `useIsPhone()`), because the 1600 Review frames draw no such subtitle and desktop is frozen; and each clause is dropped individually when its input is null (an untracked plan says nothing about scope rather than claiming 'All tracks'), reusing the page's existing `countOf` plural grammar for the reviews clause rather than a second one.

## Amendment (wave 159): the plan editor's phone copy is the frame's copy — `Criteria · N` and `Cap each` — where DEVIATIONS has not blessed a substitution

DEC-745's v4 title-row shell is a blessed structural deviation for the plan editor and is not reopened. Two divergences w13-rh measured are NOT structural and NOT blessed anywhere in DEVIATIONS.md: frame `Chautauqua Review.dc.html:601` draws the eyebrow `Criteria` with a bare count where `PlanEditor.tsx` renders `Scoring criteria`, and frame `:657` labels the per-reviewer cap `Cap each` where the app reads `Cap per reviewer`. The frame is the copy authority and neither substitution has a ruling behind it — an unblessed rewording is exactly the drift the pack exists to prevent. RULED: the phone editor renders the frame's own strings.
