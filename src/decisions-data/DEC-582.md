## Amendment (wave 31): DESIGN-RULINGS.md's atomic unit is a RULING, not a heading — one citation per heading is a coverage cap, not an identity

test/design-rulings-ledger.scan.test.ts derives its population honestly (every '## '/'### ' heading, re-derived at test time) and then honors each of its 45 rows with ONE cited artifact. But the file it guards — the mandate's second-named authority — carries 67 top-level bullets, 44 numbered items and 26 bold-led paragraphs, each an independently ruled fact; '### B8 — Interaction-states standard' alone spans roughly 85 lines under a single honored citation. Proving one artifact for a section carrying twenty rulings is DEC-100's 'A COVERAGE CAP IS NOT AN IDENTITY' at file scope, and it is why the 44px-floor ruling's own two named evasion modes could sit inside an honored heading while the campaign kept rediscovering them by hand. RULED: (a) the derived population widens from headings to RULING UNITS — every top-level bullet, numbered item and bold-led paragraph, keyed <heading-slug>::<n> with the heading kept as parent so existing honored rows survive; (b) each unit takes the file's existing three verdicts, and a unit whose ruling has no single artifact (a scope statement, a narration sentence) is recorded 'gap', never faked with a borrowed citation; (c) the new gap count is a two-sided ratchet seeded from a -1 forced measurement AND REGISTERED — an unregistered campaign constant makes scripts/exit-predicate.ts throw, which wave 28 already paid for once, so the lane must run the exit predicate and see a table before it finishes; (d) existing heading citations stay byte-identical where they still resolve and are re-pointed where they do not, per this DEC's own cascade rule.

## Amendment (wave 34): a ruling unit whose own words name an artifact is honored by that artifact, never by its parent heading's citation

RULING_UNIT_GAP_CEILING is 137 of 137 — not one derived DESIGN-RULINGS.md ruling unit is honored, so nothing in the tree verifies the campaign's own ruling document unit by unit, and the instrument's honored-citation resolver has never once been exercised on a real row. Spot-checked against the tree, that blanket verdict is wrong for at least two headings: "Fit is recorded, not averaged", the Choice radiogroup, and all four password-reset state literals resolve verbatim in the product today. A unit with no artifact stays a gap AND its missing artifact is reported as a finding, so the ledger measures conformance rather than documentation volume.
