# DEC-728: Amendment: The navigation-context map is bounded — a document-scoped cache that never evicts is an unbounded surface

`app/src/lib/useCurrentEvent.ts` keys `navigationContexts` on `pathname + search` and `releaseNavigationContext` deliberately never deletes (wave-150: a StrictMode mount → cleanup → mount with no intervening render must re-acquire the SAME pair, not throw). That deliberate choice is correct and stays; its consequence is not: the map retains one entry per DISTINCT navigation for the life of the document, so an admin SPA left open for hours grows without bound. The house rule the field guide states is UNBOUNDED SURFACE NEVER PAGED. Ruling: the map gets an explicit, named LRU bound (a `MAX_NAVIGATION_CONTEXTS` constant in the same file, insertion-ordered eviction of the oldest key, never evicting `lastCapturedKey`). The wave-150 re-acquire invariant is preserved for the current and recent navigations, which is the whole population StrictMode can re-enter. The render-phase call site is NOT moved this wave — capture is idempotent for an unchanged key, so double-render is already safe, and relocating it would rewrite four waves of receipted StrictMode reasoning; it is recorded as a separate finding.
