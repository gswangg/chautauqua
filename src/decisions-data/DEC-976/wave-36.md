# DEC-976 — Amendment (wave 36): a header-block frame scope loses its licence the moment its last receipted citation is deleted

Commit 58ea153d5 ("DEC-651 — stop asserting the four non-divergences") correctly removed four assertions from `test/desktop-control-floor.scan.test.ts`, but left the file's header block still declaring scope into `Chautauqua Speakers.dc.html` with nothing left to pay for it — `app/src/frame-citation.scan.test.ts`'s `HEADER_SCOPE_WITHOUT_RECEIPT_CEILING` went 0 -> 1. A declared target is part of the contract: the commit that removes the last receipted citation into a frame must narrow the declared scope in the same commit, or restore one fully-receipted citation. The same rule settles `app/src/pages/agenda/phoneSlots.test.ts:115`, whose citation into `Chautauqua Agenda.dc.html:182-183` has no `expect(` beneath it — a citation is not an assertion (DEC-967), and the repair is to attach it to the assertion it pays for, never to delete it.
