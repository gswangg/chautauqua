## Amendment (wave 23): `test/no-conflict-markers.test.ts`'s SCAN_DIRS is itself a hand-listed population, and the six directories it lists exclude the entire design authority

DEC-180's rule is A HAND-LISTED POPULATION IS NOT A POPULATION, and DEC-808 requires every scan to enumerate rather than name. `test/no-conflict-markers.test.ts` — the gate whose own header calls a committed conflict marker "a build break, not a formatting nit" — defines its subject as `const SCAN_DIRS = ["src", "app/src", "test", "scripts", "migrations", "decisions"]`, a six-entry hand list. It therefore cannot see `docs/`, which holds the campaign's ENTIRE geometry authority (`docs/design/*.dc.html`), its rulings (`DESIGN-RULINGS.md`), its user overrides (`DEVIATIONS.md`), its mandate (`docs/mobile-campaign.md`), all 42 audit ledgers and every probe report; nor `field-guide/`; nor any repo-root `*.md`. This is not hypothetical exposure. While planning this wave I watched the merge train leave `UU` conflicts in the shared checkout across five files, and observed three separate in-flight branches (`v12m-w21-g`, `v12m-w21-m`, `v12m-w22-j`) all editing `docs/design/DEVIATIONS.md` in the same train — the highest-collision file in the campaign, and one this gate is structurally blind to. A conflict marker landing in a `.dc.html` frame would corrupt the very artefact every ledger, verdict and ratchet is measured against, and would pass typecheck, the fast tier and the exit predicate in silence. RULED: the population is DERIVED, not listed — walk the repo root and scan every tracked text file, excluding only build/vendor output (`node_modules`, `dist`, `build`, `.git`, `.wrangler`) by the same skip-set the walker already carries, so a new top-level directory joins the population automatically instead of silently escaping it. The scan additionally must not be fooled by a marker nested inside a comment (the contacts.css conflict I observed sat entirely inside a `/* … */` block, which is exactly why it broke no CSS parse and no gate) — the check stays a raw line-prefix test over file TEXT, never a parsed-source test. A vacuous-population tripwire asserts the walked file count is non-empty and that the design pack and DEVIATIONS.md are both members, so the widening cannot silently regress to scanning nothing.
