# DEC-903: Amendment: An audit-doc handoff paragraph resolves to a live measurable or a closure marker — the fossil-prose ceiling is drained, not excused

`AUDIT_HANDOFF_STALE_CEILING` = 22 counts paragraphs across `docs/design/audit/**` matching the handoff grammar (still-open / not-fixed / for-the-planner / sized-but-not-built / future-wave deferral) that name no live non-zero constant and carry no closure marker. The field guide names this population directly: real debt hides as fossil prose, not as open rows. Spot-checking the roster confirms both failure modes co-exist. These rows are demonstrably CLOSED in the tree, listed one per pointer rather than as adjacent code spans (the DEC-008 wave-10 precedent: comma-adjacent `path:line` spans read as each other's receipt quote): docs/design/audit/public-submitted-390-v12.md:60 and :79 of that same file, docs/design/audit/docs-article-390-v12.md:83, and docs/design/audit/frame-control-floor-390-v12.md:129 — that last one already ruled in DEVIATIONS, where `Save draft` vs the frame's `Draft` is a drawing abbreviation. Others have never been re-derived at all. Ruling: each paragraph is graded against the TREE, then either (a) an append-in-place closure marker citing the live receipt that closed it — never a rewrite, the corpus is append-only per DEC-180 wave-20 — or (b) a named live non-zero constant that makes the deferral honest, or (c) the row is genuinely open and stays counted. The ceiling drops to the MEASURED value in the same commit (two-sided ratchet), whatever that value is. No lane may add a NEW handoff-grammar paragraph without a closure marker or a live constant — that is how wave 57 manufactured its own successor's red set.
