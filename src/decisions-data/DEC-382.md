# DEC-382: Amendment (wave 8): A leaving link reads label-then-mark, as all four frames draw it

Chautauqua Docs.dc.html draws the API leaving link identically at every site it appears — `API reference ↗` at :40, :129, :238 and :436, label first, mark trailing. src/routes/docs-site.tsx renders the `aria-hidden` mark span BEFORE `DOCS_API_LEAVING_LINK.label` at both of its sites (:141-145 header, :369-373 library row), i.e. `↗ API reference`. DEC-382's 'labelled leaving link' contract only requires that the label name the destination and the mark be aria-hidden; glyph position is unconstrained by it and constrained by the frames, which are unanimous. Ruled: swap to label-then-mark at both sites. Both, not one — DEC-613's second clause is the one that never lands, and a single-site fix leaves the next reader to re-litigate the other.
