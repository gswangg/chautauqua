# DEC-781: Settings' fixed grid tracks and field-width tokens are desktop geometry and collapse at 390

`.chq-settings-people-table` declares `--chq-people-grid: minmax(0,1fr) 170px 190px 200px` (settings.css:287), consumed by the header row (:304) and every people row (:720). 560px of fixed tracks plus gaps exceed the ~358px content box at 390, so the Person column collapses to zero width, Change password and Remove overlap, and the panel overflows the viewport by roughly 240px. The same class of declaration -- `.chq-settings-field-date/-seats/-name/-slug/-venue/-timezone` pinning `--chq-field-w-*` tokens (settings.css`.chq-settings-field-date {`) and the two-column grid opens with settings.css`.chq-settings-field-pair {` -- together these overflow Event-edit by 86px and CFP-edit by 46px. These widths exist to stop fields stretching across the 820px measure; that reason does not survive a 358px column. RULING: inside settings.css's terminal phone block only, `--chq-people-grid` becomes one column with each cell stacked in the card grammar the other stacked tables already use, every `.chq-settings-field-*` width becomes 100%, and `.chq-settings-field-pair` collapses to one column. Desktop tokens are untouched; the freeze holds because nothing outside the max-width block changes.


## Amendment (wave 132): Each settings edit view carries the consequence line its OWN frame draws; the data-backed three are recorded, not invented

DESIGN-RULINGS' B10 row states every settings edit view carries 'a right-aligned consequence line', and the pack draws seven distinct ones (Chautauqua Settings.dc.html:635, :726, :816, :897, :978, :1049, :1139). The slot machinery is already built (`SettingsEditForm`'s `consequence` prop, `.chq-settings-edit-consequence`), so this is not a missing capability but six heads reading the wrong words, and in Event's case a FIELD hint promoted into the head slot ('Changing the slug breaks every link already shared' is drawn at :739 as the Public URL field's own help text, not beside the H1). RULED: the three whose frame sentence is static and self-contained -- Event, People and roles, Your data -- carry the frame's sentence verbatim now, and any displaced app copy either returns to the frame position that draws it or is recorded in DEVIATIONS.md rather than deleted silently. The three that are data-backed -- Tracks and rooms ('47 submissions reference these tracks'), Speaker portal ('23 speakers can sign in today') and the saved-embed drill ('On · in use on devflowconf.com') -- are NOT built in the same breath: each needs a live referent that must be shown to exist first, and DEC-380's rule governs (a frame's drawing does not create a data model; record it, never mint it). They are named here so the next wave schedules them from a record.

## Amendment (wave 153): A frame's consequence line is part of the block it consequences; while that block is a ruled non-build the line does not render

DEC-781 (wave 133) split the pack's seven settings consequence lines into two classes: the ones whose sentence is "static and self-contained" (Event, People and roles, Your data — built verbatim now) and the ones that are "data-backed", which it deliberately did NOT build because "each needs a live referent that must be shown to exist first". Chautauqua Settings.dc.html:1139 — "Retention applies to every event in this org" — was put in the first class and is in the second. Its referent is the frame's "Keeping and deleting" block at :1161-1180, which DEVIATIONS.md §1 and §6 and DEC-032 rule a deliberate non-build (no retention column, no endpoint, no deletion job); the SAME block's other caption, :1175, is ALREADY carried in test/frame-caption-ledger/exclusions.ts's UNBACKED_EXCLUSIONS for exactly that reason. So the app today renders, on the edit view, a scoping guarantee for a setting the product does not have — DEC-851/DEC-988's declared-knob-with-no-reader in copy form, and the precise failure DEC-032 was written to prevent. RULED (DEC-781 amendment via DEC-032): a consequence line is not self-contained when its subject is unbuilt. :1139 joins UNBACKED_EXCLUSIONS beside :1175 and stops rendering; it returns verbatim, unchanged, the moment the retention block is built. The head-consequence SLOT is untouched — SettingsEditForm's `consequence` prop, .chq-settings-edit-consequence and every other panel's line stand — and no replacement copy is invented, because DEC-380/DEC-582 forbid minting a sentence no frame draws.
