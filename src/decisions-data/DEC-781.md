# DEC-781: Settings' fixed grid tracks and field-width tokens are desktop geometry and collapse at 390

`.chq-settings-people-table` declares `--chq-people-grid: minmax(0,1fr) 170px 190px 200px` (settings.css:287), consumed by the header row (:304) and every people row (:720). 560px of fixed tracks plus gaps exceed the ~358px content box at 390, so the Person column collapses to zero width, Change password and Remove overlap, and the panel overflows the viewport by roughly 240px. The same class of declaration -- `.chq-settings-field-date/-seats/-name/-slug/-venue/-timezone` pinning `--chq-field-w-*` tokens (settings.css:827-853) and `.chq-settings-field-pair`'s two-column grid (:887) -- overflows Event-edit by 86px and CFP-edit by 46px. These widths exist to stop fields stretching across the 820px measure; that reason does not survive a 358px column. RULING: inside settings.css's terminal phone block only, `--chq-people-grid` becomes one column with each cell stacked in the card grammar the other stacked tables already use, every `.chq-settings-field-*` width becomes 100%, and `.chq-settings-field-pair` collapses to one column. Desktop tokens are untouched; the freeze holds because nothing outside the max-width block changes.
