# DEC-069: Machine-greppable stage-1 exit predicate in docs/verification-log.md (RESULT:/OPEN ITEMS: lines); green counts only for its named sha

## Amendment (wave 116): the v12 campaign's exit condition is machine-derived from the ledgers' own exported constants, never hand-derived by the planner each wave

The campaign's goal — every screen matching its v12 frame on desktop and phone — is already fully instrumented: test/desktop-frame-ledger.scan.test.ts exports CLAIMED_FLOOR (71 of 102, plus 2 DEVIATIONS-§6 exclusions), test/phone-frame-ledger.scan.test.ts exports CLAIMED_FLOOR (53 of 53), and the Tier-2 sweeps export CEILING (28), ANCHOR_FLOOR_OFFENDERS_CEILING (58), OVERFLOW_OFFENDERS_CEILING (18), PHONE_HIDDEN_UNRECEIPTED_CEILING (6), SSR_UNFLOORED_TOKENS_CEILING (3) and DESKTOP_UNRECEIPTED_CLAIM_CEILING (15). Those constants were promoted to module scope precisely so they could be found and re-measured from outside their files (control-font.scan.test.ts:174-186 says so). Yet scripts/exit-predicate.ts — the DEC-069 gate itself — contains not one reference to any of them, so every wave the campaign's distance to done is re-derived by hand from prose that decays, which is exactly how three consecutive waves shipped plans against a red set that had already inverted. RULED: the exit predicate imports the exported constants and reports the campaign's distance to exit as data. A hand-listed population is not a population (DEC-180/DEC-808); a hand-derived exit condition is not an exit condition.

## Amendment (wave 118): the campaign exit predicate's ratchet population must be TOTAL — every campaign ceiling is graded or carries a principle-shaped out-of-scope reason

`scripts/exit-predicate.ts`'s `CAMPAIGN_CONSTANT_NAMES` is a hand-listed population of 12 names — precisely the shape DEC-180/DEC-808 forbid ("a hand-listed population is not a population"). Measured against the tree there are 17 `*_CEILING`/`*_FLOOR` constants plus control-font's bare `CEILING`; NINE are ungraded, and one of them is `MARKUP_PHONE_UNHIDDEN_CEILING = 34` — thirty-four markup-mounted phone classes with no top-level `display:none`, i.e. phone affordances painting on desktop. `DIVERGENCE_CEILING` (the mandate's own Tier-2 density-pairing sweep) is ungraded too. As it stands the machine can print `CAMPAIGN: DONE` while the campaign's own instruments are red, which converts the exit predicate into decoration — the exact failure wave 115 named when a train landed over a live ratchet. RULED: the predicate derives the candidate set mechanically from the campaign scan files' source text and asserts totality — every derived constant is either GRADED (counted toward desktop/phone/Tier-2) or named in an exported `OUT_OF_CAMPAIGN_SCOPE` map whose value is a PRINCIPLE (a fact about the code that survives every branch name and wave number being deleted, per DEC-099's shape), never a schedule. A constant that is neither fails the predicate loudly.
