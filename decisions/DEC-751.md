# DEC-751: Recent sends live under Compose as well as in History — one component, two mounts, four rows and a link

docs/design/Chautauqua Comms.dc.html:146-155 ends the compose column with a "Recent sends" section whose rule carries an "All history" link and whose rows read when · subject · N sent · template. On main that list exists only inside the History tab (app/src/pages/comms/HistoryTab.tsx:98), so an organiser composing a send cannot see what already went out — the exact context that prevents sending the same batch twice. The list is extracted into one presentational component fed by the existing GET email-log (?groupBy=batch) and mounted in both places; the compose mount is capped at four rows, is read-only (no recipients disclosure — that belongs to the full history), and its "All history" link switches the DEC-710 ?tab= URL state rather than navigating away. Failed and partially failed batches appear here exactly as History renders them: an attempted send is auditable whatever the transport did.
