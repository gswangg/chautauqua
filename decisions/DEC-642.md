# DEC-642: The audit's "deliberately not built" list is machine-falsifiable: every bullet carries an absence marker, and the test fails when the named artefact EXISTS

test/audit-claims.test.ts enumerates route paths only, so the fastest-ageing part of docs/AUDIT.md drifted freely: it currently claims four shipped capabilities are missing — per-item unplaced reasons (src/domain/schedule.ts's UnplacedReason), the hardened embed element (public/embed.js + test/embed-element.test.ts), the Sessionboard import route (src/routes/api/import.ts), and an anonymity policy DEC-624 resolved as a ratchet. An audit that understates the product is as wrong as one that overstates it, and README:151 currently promises it "cannot drift". A claim of absence is testable in exactly the way a claim of presence is: name the artefact (file / exported symbol / registered route) and assert it is not there.
