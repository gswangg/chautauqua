# DEC-055: Show-flow export: GET /api/v1/events/:eventId/exports/showflow.csv

SPEC §10.7 names the show-flow export (final titles, full speaker lists, intro text, deck locations) and producers actually run events off this sheet. Organizer-only CSV alongside the existing exports: accepted submissions ordered by day, start, room; columns ref, title, description, day, start, end, room, tracks ('; '-joined names), speakers ('; '-joined participant full names in participant order), deck_file (latest presentation-kind file name + version number, empty if none), deck_url (/files/<fileId>, empty if none). Built from joined queries — no per-row N+1 (SPEC §7). Unscheduled accepted sessions appear last with empty day/start/end/room, never silently dropped.
