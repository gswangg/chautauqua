# DEC-514: The stage-1 exit wave carries ZERO product-behavior tasks, because evidence cut at a wave's base sha cannot describe that wave's own fixes

This is the structural reason waves 25, 26 and 27 each owed a closing ledger and none could deliver one. Evidence lanes run on branches cut from the wave's starting main, so a lane's `git rev-parse HEAD` names a sha that predates every product fix merged in the same wave — task-w27-c's build/test artifact freezes 2950e40, a sha whose log contains only wave-26 merges, while DEC-505 and DEC-506 landed after it. DEC-497 and DEC-507 already rule that evidence predating a rework is not evidence about it, so each wave's own evidence self-invalidates and the ledger is deferred again: a regress with no fixed point as long as the closing wave also changes product code. Decision: the exit wave is verification-only. Every lane in it is read-only over src/ (source-scanning tests and markdown artifacts excepted), so its base sha already contains every landed fix and its measurements are true statements about the shipped product. Wave 28 is therefore explicitly NOT the exit wave — it carries four product-behavior lanes (DEC-508/509/510) plus two lock-in lanes — and stage-1 completion is not claimed here. The wave that follows, containing no product task, is where build/test, the J1-J12 four-persona walkthrough, the desktop+390x844 render sweep, the 2k-submission/800-speaker perf smoke, and the DEC-496/507 closing ledger are cut, and where a single explicit verdict is rendered.
