# DEC-064: Claim POST validates before consuming: consumeClaimToken runs only after all validation passes, immediately before user creation

POST /claim/:token currently calls consumeClaimToken (src/routes/auth.tsx:181) before the password min-length check (:188), so one too-short password from any non-browser client irreversibly burns the speaker's one-time account-creation link (subsequent GETs 410). Decision: the validation phase uses readClaimToken (peek, already exported from src/auth/claim.ts:63); rate limit first, then peek (missing -> 410), then password validation (failure leaves the token claimable), then contact lookup and duplicate-user redirect using the peeked record; consumeClaimToken is called only on the success path immediately before inserting the user, and a null consume at that point (lost race) is a 410 not_found. The token is destroyed on exactly one path: successful account creation.

## Amendment (wave 66): a one-time grant is spent by the write that succeeds, not by the attempt

auth-claim.tsx:117 consumes the claim token, THEN inserts the user (:125), THEN revokes any outstanding reset grant (:141), THEN issues the session (:143). Any throw past :117 -- a D1 transient, a unique collision on the global user-email index, a KV failure -- burns the speaker's only claim link with no account created and no speaker-side re-mint path. DEC-064's own rule, quoted verbatim at :66-68 ("any validation failure below must leave the one-time link claimable"), is honoured for the validation phase and abandoned for the write phase it precedes. RULING: the INSERT is the serializer -- the unique index, not the KV consume, is what makes a second claim impossible -- so `consumeClaimToken` moves BELOW the insert. A unique-collision on insert maps to the same `/login` redirect the pre-check at :110-113 already returns (leaving the grant unconsumed and the link still usable). After the row exists, a KV or session failure is recoverable (the speaker signs in at /login with the password they just set) and stays a loud throw. Same doctrine as DEC-547: nothing irreversible happens above the point of no return.
