# DEC-161: Render-smoke completion policy: one *.render.test.tsx per top-level page/tab-view component, ownership split by app/src/pages subdirectory, scoped to what exists on main at branch time

DEC-144 layer 2 mandates component render smokes with fixture-shaped mocks, but only 4 pages have them. Policy: every top-level page or tab-view component under app/src/pages/** gets a co-located *.render.test.tsx that mounts it against app/src/test-utils/mockApi.ts payloads mirroring REAL envelopes ({items,total,page,perPage} lists, single-object /events/:id/forms, nullable date fields per DEC-146) and asserts it renders a marker element with zero console.error (spy that fails the test). One test per page-level component, not per widget — mounting the page exercises its children. Ownership is by directory so parallel lanes never collide: {review, comms, agenda} in one lane, {contacts, speakers, settings, forms} in another, and any NEW page introduced by a feature task ships its render test inside that same task. Scope is 'what exists on main when you branch': wave-2 pages get covered automatically as they land, without serializing on the merge train; mockApi.ts edits must be additive-only, preferring test-local helpers.
