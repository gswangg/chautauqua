# DEC-710: A tab strip's selection is URL state (?tab=), never component state

Comms' Templates/History and the Contacts panels are useState tabs: not bookmarkable, wrong under back/forward, and unlinkable from a report or a colleague's message. The same root cause produced the nav-active-state bug (state derived from clicks rather than the URL). A `?tab=` search param read via useSearchParams is deep-linkable and back-button-correct without touching the route table -- so two tasks can adopt it in parallel without both editing App.tsx. aria-selected is derived from the URL, never from a click handler's memory.
