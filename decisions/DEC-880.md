# DEC-880: A reset scopes to the properties it means: a chip trigger never strips its family's outline; and Add speaker is a dialog, not a page-displacing panel

app/src/pages/speakers/speakers.css:211 sets `.chq-participation-menu-trigger { border: none }` to make the menu trigger read as a chip. It lands after the four .chq-speakers-status-* modifiers, so it flattens three of DEC-730's four participation states — only the filled Confirmed variant survives, and a four-state vocabulary renders as one. A reset joins a family; it may neutralize what a <button> brings (appearance, background, padding, font inheritance, cursor) but never a property the family it joins depends on. Separately, RosterPanel's mode==='add' returns an inline fragment that displaces the roster down the page; the v5 mock renders a centered ~740px modal in the section's chq-form-row language. Every dialog in this product goes through the ONE dialog contract (app/src/components/ModalFrame.tsx) — a second, page-shaped way to open the same form is one too many.
