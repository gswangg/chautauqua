# DEC-582: GET / is an anonymous surface: signed-in visitors are redirected by role, and it is styled from the public CSS family — revising DEC-382 for / only

Today GET / never reads c.var.auth and shows an operator link farm ('Admin', 'Speaker portal', 'Dev mailbox') to everyone including strangers. The v2 handoff makes / the org's event hub — the masthead carries the ORG's name, the product is named exactly once in a footer GitHub attribution, and the only auth affordance is a quiet Sign in. It therefore only ever renders for anonymous visitors: organizer and reviewer sessions redirect to /admin, speaker sessions to /portal, matching the redirects /admin already performs. DEC-382 filed /, /docs/api and /dev/mailbox together as 'chrome, not designed screens' sharing TOOLS_CSS; that verdict is now wrong for / alone, which draws ThemeStyles + the public CSS family + its own HOME_CSS module. /docs/api and /dev/mailbox stay chrome under DEC-382 unchanged. The dev-mailbox link disappears from / rather than being auth-gated: the only role that could see it now redirects away before the page renders.

## Amendment (wave 48)

**The anonymous hub obeys 'chrome is full bleed': the 900px bordered shell is stripped, content sits at the 820 reading measure.** DEC-582 put GET / on the public CSS family. HOME_CSS then wrapped the whole page in `.chq-home-shell { max-width: 900px; border: 1px solid …; border-radius: 6px }` (home.css.ts:18) — a card floating on the paper ground, which docs/design/README.md §Widths forbids in the same sentence it defines the width system: 'Chrome is always full bleed. The header rule, the toolbar rules and section rules run edge to edge; only the content inside them is constrained.' RULING: the shell loses max-width, border, radius and its own background; the header rule, the footer rule and the footer's sunk fill run edge to edge; the CONTENT of header, body and footer sits in an 820 centred measure (the README's named reading measure — chosen over the fleet's derived 732 because a fleet measurement is not authority over the handoff's stated number). The 900px frame width is a drawing width, exactly as the README says of its own 1240 frames.

## Amendment (wave 81): the home hub's measure is read from the vendored Home frame, not measured off a picture of it

Five gates (9, 10, 11, the delta probes and the wave-78 design-agent verdict) argued 820-vs-732 from RENDERED frame pixels, and wave 56 closed it NOT-A-DEFECT by citing docs/design/README.md's §Widths table — which lists Overview, session detail, the CFP form and login, and does NOT list the hub. The vendored frame settles it in bytes: `docs/design/Chautauqua Home.dc.html:38` is `max-width:820px; margin:0 auto; width:100%; padding:36px 44px 40px` — an 820 CONTAINER whose CONTENT box is 820-2x44 = 732 — while `:33` (header `padding:15px 44px`) and `:101` (footer `padding:18px 44px`) are full-width chrome with 44px gutters, i.e. content spanning 1512 at the frame's 1600, not a centred 820. The implementation gives all three the same centred `max(34px, calc((100% - 820px)/2))` (`src/routes/public/home.css.ts:21`), which matches neither the body nor the chrome and whose 34px minimum has no source. Ruling: the hub's layout derives from the vendored Home frame; where the README's table and a surface's own frame disagree about a surface the table does not name, the frame wins; a gate's pixel measurement is evidence about a rendering, never authority over the drawing.

## Amendment: /docs (user-facing) is the second revision of DEC-382; /docs/api and /dev/mailbox stay chrome and are reached as labelled leaving links

DEC-582 revised DEC-382 for `GET /` only, moving one operator surface into the public CSS family and saying so explicitly. The v12 ruling (docs/design/DESIGN-RULINGS.md:300-306) asks for the identical move for a NEW `/docs` site and pointedly declines to restyle `/docs/api`: "that is a second revision of DEC-382 and needs saying explicitly." Ruling, said explicitly: the user-facing `/docs` site is designed content and joins the public CSS family; `/docs/api` (DEC-056) and `/dev/mailbox` remain TOOLS_CSS chrome and are reached from the docs as labelled LEAVING LINKS ("Leaves the docs — an operator surface", ↗ muted), never presented as articles. The seam is real and the design names it rather than hiding it. Measures: prose 680, figures 900 — the one sanctioned measure break in the bundle; on phone figures go edge-to-edge with the caption inset.
