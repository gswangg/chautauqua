# DEC-633: The reviews are readable where the decision is made

DEC-596 put every evaluation behind GET /api/v1/submissions/:id/evaluations and rendered it on submission detail, which closed half of the judge's MAJOR 'reviewer comments are write-only' finding. The other half stands: Results — the ranked screen that owns Accept/Decline — still shows numerics only, so the organiser decides without the one artefact the round produced. Decision: a results row expands in place to the evaluations the existing endpoint returns, rendering exactly what the server sent, including its reviewer field verbatim (DEC-622 decided anonymity server-side; no surface re-decides it, and a withheld name reads '(anonymized)', never blank). Comments render at full length — chrome is terse, sentences are for people.
