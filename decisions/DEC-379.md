# DEC-379: app/src/styles.css closes the SPA's class vocabulary, and a test proves closure; the residual chrome names are adopted, not renamed

The wave-1 shell lane replaced the old 327-line stylesheet wholesale, so 104 references across 43 SPA modules now point at classes nothing defines: `.chq-page`, `.chq-attention-frame`, `.chq-error-banner`, `.chq-toast`, `.chq-loading`, `.chq-card`, `.chq-field`, `.chq-field-error`, `.chq-checkbox-label`, `.chq-modal-actions`, `.chq-modal-title`, `.chq-modal-close`, `.chq-modal-error`, `.chq-event-switcher`. Every error banner, toast, page wrapper and field error in the product is currently unstyled. Renaming 104 sites across 43 files owned by six different lanes would be a merge disaster for zero user-visible gain, so the vocabulary is CLOSED BY DEFINITION instead: styles.css (the DEC-368/372 single-owner sheet) defines the names the tree actually uses, `.chq-error` and `.chq-error-banner` share one rule, and every one of them is set in the DEC-367 palette — the error banner is sunk-surface + ink + weight 600, never red, and the field error is 11px/700/0.1em uppercase ink. A new describe block in test/design-system.test.ts scans every non-test .tsx under app/src, extracts `chq-[a-z0-9-]+` tokens from className literals (skipping fragments that are interpolated or end in `-`), and asserts each is defined as a class selector in some app/src/**/*.css — so no lane can ever again ship a class name with no rule behind it. `.chq-page` is a vertical stack (flex column, gap 26px), NOT a measure: Agenda and the wide tables need full bleed, and the 820px Overview measure is `.chq-measure` applied at the page. The same lane owns src/views/theme.ts (DEC-372's standing rule that the two token files are one lane) and adds `--chq-ink-strong: #2E2A24` — the handoff's literal secondary-button ink — to both files, replacing theme.ts's raw hex and styles.css's substituted `--chq-ink-2`, which had silently drifted the two runtimes' button tiers apart.
