# DEC-615: Auto-schedule reports a reason per unplaced session, from a closed vocabulary with one renderer

autoSchedule returns { placed, unplaced: { submissionId, reason }[] } where UnplacedReason is a closed union: 'no_rooms_configured' | 'duration_exceeds_day' | 'no_free_slot' | 'speaker_double_booked'. Prose lives in exactly one describeUnplaced(reason, labels) sitting beside describeConflict — the enum never carries prose and the renderer never invents a reason. Placement behaviour is unchanged (same greedy order, same output placements); this is reporting only. Copy rule: name the constraint, promise nothing — 'No free 45-minute slot in any room on any day', not advice about widening the day.
