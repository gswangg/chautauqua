# DEC-303: Wave-11's freeze is derived per-lane behind a seven-item WAVE-10 CONTENT GATE, not a planner-declared literal sha (main was provably mid-flight during planning)

DEC-270 step 1 requires the planner to write a 40-char literal into every battery task, and DEC-287 made that literal part of the exit predicate. Both are unsatisfiable this wave, and I confirmed it by reading .git rather than inheriting it: at the start of planning refs/heads/main was 745845d24d1fb0f260b3f06ab86dad2eb8d4f869 (reflog line 105, `merge task-w10-a`, six of seven wave-10 branches unmerged); by the time I re-read origin.ts it had advanced to be82de54ce5c6bda1c625edbc28c192971554d56 with a, c, e, d, b and g landed and only task-w10-f (DEC-300, the form-field cascade) still in flight. A literal named now would freeze a tree that is provably still moving — the exact failure DEC-256/DEC-262/DEC-270 each took a turn at and lost. So replace declaration with a CONTENT GATE, which is what the literal was ever a proxy for: each lane runs `S=$(git rev-parse refs/heads/main)`, then greps seven wave-10 facts at S — G1 `src/routes/root.tsx` contains `res.status !== 304` (DEC-295); G2 `.dev.vars.example` contains `PUBLIC_BASE_URL=http://localhost:8787` AND `src/server/origin.ts` contains `firstLoopbackCandidate` (DEC-296); G3 `src/routes/public/index.tsx` sets `Cache-Control: no-store` on the non-200 path (DEC-297); G4 `src/routes/agenda.ts` contains `parseBoundedInt` and `gridMin: { min: 1, max: 480 }` (DEC-298); G5 `src/server/repo/attribution.ts` exists and contains `isNull(schema.participant.titleAtTime)` (DEC-299); G6 `src/routes/api/forms.ts` + `src/server/repo/forms.ts` implement the 409/`cascade=1` field delete (DEC-300); G7 `src/routes/api/events.ts` contains `name: "General"` at event create (DEC-301). Six of the seven were already verified present by me at be82de54; G6 was not. A lane whose S misses any item sleeps 60s, re-reads refs/heads/main and re-gates, up to 15 minutes, then proceeds and records `WAVE-10 GATE: MISSING <ids>` with each missing id counted as one OPEN ITEM. A lane whose S passes records `WAVE-10 GATE: PASS`. Verification still happens only inside `git worktree add --detach <scratch> $S` with `git merge-base --is-ancestor $S refs/heads/main` confirmed (DEC-270 steps 1/2/4 otherwise unchanged). Because wave 11 emits ZERO product commits, DEC-280's `git log --oneline $S..refs/heads/main -- src app migrations scripts test` MUST come back empty for every lane; a non-empty product delta means the zero-product-commit rule was violated and is itself an OPEN ITEM to be re-checked at the tip.
