# DEC-183: DEV_MODE moves from wrangler.jsonc vars to a committed .dev.vars; deployable config never mounts /dev/mailbox

wrangler.jsonc:39-41 bakes DEV_MODE='1' into the config wrangler deploy would ship, and DEV_MODE is the sole gate on /dev/mailbox, which exposes claim links and one-time passwords — a stage-2 deploy would publish a credential leak. Stage-1-safe fix with zero behavior change locally: delete the vars block from wrangler.jsonc (leave a '// DEC-183' comment noting production must not set DEV_MODE), commit a .dev.vars file containing DEV_MODE=1 (not a secret; wrangler dev auto-loads .dev.vars, so walkthrough/render-sweep/perf harnesses and the speaker.ts:401 mailbox assertion keep working untouched), and remove the .dev.vars line from .gitignore so the repo stays zero-setup. shouldMountDevMailbox and its tests are already correct and unchanged.
