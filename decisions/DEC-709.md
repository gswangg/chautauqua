# DEC-709: Locked criteria are not a dead end: 'Start a new wave' carries the frozen criteria into a new round, and the plan editor is a summary plus inline rows

DEC-213/676 froze criteria once reviews are scored -- correct, and the design pack agrees -- but a freeze with no forward move reads as a bug to the organizer, and it leaves the plan's `rounds` field decorative (the sbek judge called that MAJOR). The README names the way forward explicitly: 'Start a new wave'. Implementing it as rounds+1, with the criteria in force copied into roundCriteria[newRound] as an editable override and currentRound advanced, gives rounds real semantics using machinery that already exists (DEC-147 per-round criteria, advance-round) and no schema change. The same decision fixes the page's shape: plan settings are a compact summary block, the criteria list is the page's primary content in inline rows (the form-builder pattern the README names), not a stack of raw labelled inputs.
