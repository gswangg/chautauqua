# DEC-406: Every interactive control in the admin SPA carries a shell class; three surfaces never got the redesign's control tiers, and each gets its own lane before any repo-wide guard

The redesign's premise (docs/design/README.md: "functionally complete but visually unstyled ... browser-default form controls") is only half delivered. A source read of app/src finds exactly three surfaces still rendering browser defaults, and they are not minor: (1) app/src/pages/submissions/SubmissionDetailPage.tsx — nine of ten buttons unclassed (:332 Edit, :355/:358 Save/Cancel, :387 Restore revision, :479/:489 co-presenter Search/Add, :552/:559 Approve / Ask for changes, :566 Clone) plus the edit form's <input>/<textarea> (:340/:349), the co-presenter search (:465) and a <select> (:538); (2) app/src/pages/comms/ComposeWizard.tsx steps 'select' and 'template' — only step 3 was re-skinned, so :265/:272/:294 inputs, :281 a non-chq-table picker table, :318/:321/:326/:370/:373/:472 buttons, :337 select, :362 subject, :366 body are all defaults; (3) app/src/pages/forms/FieldModal.tsx — J1's "add a custom question" dialog, every control unclassed (:104/:139/:152 selects, :115/:162 text, :120/:131 textareas, :124 checkbox, :169/:172 actions) plus FormsPage.tsx:160. Everything else (contacts, settings, review, content, agenda, speakers, templates) is already conformant, so this is a bounded three-lane fix, not a sweep. The vocabulary is fixed here so no lane invents its own: exactly one `chq-btn chq-btn-primary` per action group, `chq-btn chq-btn-secondary` for its siblings, `chq-btn chq-btn-tertiary`/`chq-link-button` for inline row actions, `chq-input`/`chq-select`/`chq-textarea`/`chq-check` on fields; layout only in the page's own stylesheet under a page-prefixed name, never redefining a shared class (DEC-368); shared classes already supply the 44px phone floor (DEC-393) so no lane restates it. The repo-wide source guard that would make this non-recurring is deliberately NOT in this wave: three parallel lanes each fix a third, and a guard cut from main would either land red or duplicate their work. It lands in wave 9 against a clean tree.
