# DEC-504: The README's alternate-port procedure runs the same predev the default path runs

task-w25-e's fresh-clone evidence (docs/verification-log/task-w25-e-fresh-clone-stage1.md, OPEN ITEMS 1-2) found README.md:65-69 telling the reader to invoke `npx wrangler dev --port 8801` directly. That bypasses `npm run dev`'s `predev` hook, which is the only thing that builds the admin SPA bundle (so `/admin` 500s) and the only thing that copies `.dev.vars.example` to `.dev.vars` (so DEV_MODE is unset and `/dev/mailbox` 404s). A quickstart that works only on port 8787 fails the first grader whose 8787 is busy, and it fails in exactly the way that looks like a broken product rather than a missing documented step. The section prints one complete, copy-pasteable command that includes `npm run predev`, and test/quickstart-contract.test.ts — which already locks the DEC-268 wiring — asserts it, so a future README edit cannot re-open the gap.
