# DEC-194: FieldControl emits data-required="true"/"false" on the four required-capable controls, restoring the DEC-008 visibility script's dataset.required contract

form-render.tsx:167 sets input.required = visible && input.dataset.required === 'true', but no control renders a data-required attribute, so the first apply() strips the required flag from every rule-gated field even while visible — conditionally-required fields silently lose J2 browser gating and degrade to full-page server 400 round-trips. Fix at the source the script already expects: add data-required={field.required ? "true" : "false"} alongside the existing required attr on the text, long_text, dropdown, and number controls (form-render.tsx lines 26, 37, 43, 65). checkbox and file controls never carry browser required today and stay that way; server validation (src/forms/validate.ts) remains authoritative and unchanged.
