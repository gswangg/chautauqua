# DEC-044: Plan-reviewer assignments addressed by plan_reviewer.id

The SPA already calls GET /plans/:id/reviewers and DELETE /plans/:id/reviewers/:rowId but the server only implements POST and a body-addressed DELETE — the reviewers panel 404s. Canonical REST shape: GET /api/v1/plans/:id/reviewers returns {items:[{id,userId,email,trackId,submissionId}]}; DELETE /api/v1/plans/:id/reviewers/:reviewerId removes by plan_reviewer row id after asserting row.planId matches the owned plan. The body-based DELETE is removed outright (house rule: no backwards-compat shims).
