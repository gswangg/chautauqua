# DEC-257: Fresh-clone evaluator bootstrap is a battery section: the stranger test the swarm's own gates structurally cannot run

DEC-252's origin defect survived 28 rounds of green gates because every existing gate runs inside a swarm worktree that already has node_modules, warm .wrangler state, a .dev.vars written by a previous run, and a hand-picked non-default port. SPEC section0/section8 promise something none of those gates measure: a stranger can `git clone`, then `npm i && npm run db:migrate && npm run seed && npm run dev`, with zero secrets and zero external accounts, and reach a populated demo event whose README 'For evaluators' table is verbatim true.

Section g therefore clones the frozen sha into a clean directory OUTSIDE the repo (no node_modules, no .wrangler, no .dev.vars carried over), follows the README literally on the DEFAULT port 8787 with no extra --var flags, drives a real chromium browser through all four seeded persona logins and every route in the evaluator table, submits the public CFP form, follows the confirmation claim link through account creation into /portal, and asserts that every absolute http(s) link in the /dev/mailbox rendered message body resolves to localhost:8787.

An off-origin (chautauqua.cc) link, a missing README credential, or any step that requires a secret is an OPEN ITEM, not a footnote. The inspector-port flag is the single permitted deviation from README-verbatim, and only when a concurrent lane has taken 9229; it must be stated in the log.
