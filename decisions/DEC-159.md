# DEC-159: CNT-13 central files library: event-scoped deliverables grouped by previous_file_id version chains, exposed as GET /events/:eventId/files and a Files view inside ContentApp

CNT-S3 step 5 requires a files view listing slides.pdf with its session and speaker association, upload date, and a version count of 2 — the DEC-145 seed already provides that data. Design: src/server/repo/files.ts gains listEventDeliverableFiles(db, eventId) returning one item per version chain: {rootFileId, latestFileId, filename, kind, submissionId, submissionRef, submissionTitle, speakerName, uploadedAt (latest version's), versionCount}, assembled by following previous_file_id links (event-scoped, so bounded); exposed at GET /api/v1/events/:eventId/files (organizer-only, standard list envelope) in src/routes/files.ts. UI: a top-level Worklist | Files view toggle in ContentApp; the Files view lists chains with multi-select checkboxes and links into the existing DeliverableDetail so the version list and comment thread stay one implementation. No new tables — the file schema already carries the chain.
