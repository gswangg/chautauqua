# DEC-724: The null-room agenda column is conditional, and it is called "No room yet"

The grid's trailing column is the null-room bucket — sessions with a time but no room — which is a real and useful capability (time-first placement) but not a room, which is why Settings correctly refuses to delete it. Rendering it unconditionally spends a fifth of the grid on an empty column and labels it with an internal shorthand the public side was already made to stop leaking (DEC-666). Hiding it outright would remove the capability, so the condition names both moments it is needed: it appears when at least one placement on the visible day is roomless, and while a session is armed for placement. Header copy becomes plain vocabulary — 'No room yet' — and the accessible names of the placement buttons follow it, so the keyboard path reads the same sentence the eye does.
