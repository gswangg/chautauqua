# DEC-002: Pure-core + ports architecture; plain-vitest testability

All domain logic (auth crypto, form validation, status pipeline, acceptance planning, schedule conflicts, mail rendering, .ics, CSV) lives in runtime-agnostic modules under src/{auth,domain,forms,mail,lib}/ with NO node:/cloudflare imports — only Web APIs (globalThis.crypto, TextEncoder). These test under plain vitest in node and run unchanged on Workers. All I/O goes behind ports (Mailer, EmailLogWriter, FileStore, Clock) defined as TypeScript interfaces next to their domain; route handlers in src/ wire ports to D1/R2. Domain modules type their inputs as plain interfaces, never drizzle row types, so core modules compile without the schema module. This is what makes stage-2 adapter swaps (Resend, presigned R2) configuration-only, per SPEC §0.
