# DEC-037: Email HTML built only via escapeHtml/textToHtml in src/mail/render.ts

Five send sites interpolate user- or producer-controlled text into HTML bodies raw (comms.ts:259, api/contacts.ts:411, public/submit.tsx:398, review.ts:309, repo/tasks.ts:498); the dev-mailbox iframe sandbox masks it in stage 1 but the stored body_html is delivered verbatim once the Resend adapter lands. Canon: src/mail/render.ts exports escapeHtml(s) (escapes & < > " ') and textToHtml(text) (escape, then blank-line-separated <p> blocks with <br/> for single newlines). Every mailer.send html field is built from these; renderTemplate must never be called with an HTML template whose vars carry user content. Anchors are built by callers with both href and text escaped.
