# DEC-635: A request the router cannot answer still gets our answer: the API gets the envelope, a human gets a page

No app.notFound() handler is registered anywhere, so every unmatched path falls through to Hono's default bare-text '404 Not Found'. Two consequences: /api/v1/<typo> answers text/plain instead of the {error:{code,message}} envelope every other API failure promises (DEC-013), so a client cannot parse our errors uniformly; and any mistyped human URL is an unstyled dead end on a product whose design pack ships a not-found screen. Decision: one handler, registered once in the base app from its own module, classifies by the /api/v1 prefix — envelope for the API, an SSR 404 page (public CSS family, noindex, links home and to sign-in) for everyone else. ApiError-thrown 404s keep flowing through the existing error handler untouched.


## Amendment (wave 40)

**The public 404 imports the CARD, not just its stylesheet — one component, or it is two documents again**

Verified on main: src/server/not-found.tsx and src/routes/public/not-found.tsx both claim to draw DEC-945's one card, and they diverge on every visible fact — title 'Not found - Chautauqua' vs 'Not found', eyebrow = the event name vs the literal 'Not found', two links vs one, <main class=card> vs a bare <main> wrapping a <div class=card> (which shrink-wraps to 293.9px because the bare main is not the card), noindex vs no noindex, ThemeStyles+AUTH_CSS vs BaseStyles+AUTH_CSS. Sharing a stylesheet is not sharing a card: the markup is where the divergence lives, so the shared thing must be the component. RULING: src/server/not-found.tsx exports the page renderer (eyebrow + body message + both links + noindex + title), and the public 404 calls it, keeping only what is genuinely its own — the caller-supplied message and DEC-297's Cache-Control: no-store on the 404. Out of scope, deliberately: the /admin/* SPA catch-all's HTTP 200. The Worker cannot know the SPA's route table without duplicating app/src/routeManifest.ts across the src/ boundary, and a wrong 404 on a real admin route is worse than a right 200 on a typo.
