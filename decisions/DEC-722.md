# DEC-722: A detail page spans the same measure as its sibling list pages, and its decision panel decides only

Two deviations with one cause. The submission detail page hard-codes a 720px main column plus a 320px aside, so on a wide screen its sections lean left with dead space right while /admin/submissions fills the frame — the user's complaint, and the fix is to let the main column be minmax(0,1fr) inside the shared page container rather than to invent a third per-page width. The same panel also carries Approve content / Request changes, which imports the Content screen's job into the decision screen; the README's 'two screens' rule puts content decisions where the versions and the note thread are, and DEC-720 now makes asking for changes require a note that this panel has nowhere to compose. The decision panel decides status; it links to content.
