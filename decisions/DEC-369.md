The handoff's layout pattern is a 1px-ink-bottom-bordered header (padding 15px 34px) holding the lowercase 'chautauqua' wordmark (Familjen Grotesk 22px/700/-0.03em), a 13px/600 nav row with gap 15px, and right-aligned event name (13px/600) plus user identity (11px/700/0.1em uppercase muted) with Sign out — so the 220px .chq-nav sidebar in app/src/App.tsx is deleted, not restyled, and main becomes padding 26px 34px 34px with an 820px measure on Overview and 660-760px on forms.
