# DEC-369: Admin chrome: top header with horizontal nav replaces the sidebar; phone gets a five-item tab bar; nav carries destinations and exceptions only

The handoff's layout pattern is a 1px-ink-bottom-bordered header (padding 15px 34px) holding the lowercase 'chautauqua' wordmark (Familjen Grotesk 22px/700/-0.03em), a 13px/600 nav row with gap 15px, and right-aligned event name (13px/600) plus user identity (11px/700/0.1em uppercase muted) with Sign out — so the 220px .chq-nav sidebar in app/src/App.tsx is deleted, not restyled, and main becomes padding 26px 34px 34px with an 820px measure on Overview and 660-760px on forms. Nav shows destinations only: NO counts (the old sidebar duplicated Overview's numbers), and an ink/olive badge ONLY when something is wrong ('3 LATE', '2 CLASH'), sourced from the retained overview aggregates speakers.overdueAssignments and agenda.conflicts (DEC-370) — when those are unavailable the badge simply does not render, which is absence of an exception, not a swallowed error. At 390px the header collapses to wordmark + event name + a horizontally scrollable chip strip, and a fixed five-item bottom tab bar (Overview, Submissions, Speakers, Content, More) with an olive dot on the active item; 'More' opens a sheet listing Review, Agenda, Comms, Contacts, Settings, Sign out. Role gating is unchanged: reviewers still see only Review and RoleGate still bounces them there (DEC-024).
