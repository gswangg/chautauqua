# DEC-046: Event switcher + New-event modal in the SPA header; switch = localStorage + full reload

J1 says a producer creates an event and J11 assumes multiple events per org, but the SPA silently pins events[0]. A header EventSwitcher (app/src/components/EventSwitcher.tsx) lists GET /events, marks the current id, and switching writes localStorage 'chq.currentEventId' then window.location.assign('/admin') — a full reload is the simplest correct invalidation of every page's cached event scope. 'New event…' opens a modal posting the existing POST /api/v1/events contract (name/slug/startDate/endDate/timezone/location), then switches to the created event and lands on /admin/settings. No server changes in this decision (form provisioning is DEC-050).
