# DEC-594: An embed is a closed surface, and a query parameter is either honored by both renderings or deleted

Three verified defects share one root: /embed accepts parameters it silently drops and emits links that leave the iframe. `fields=` is parsed and applied to the HTML cards but ignored by the .json twin; `day=` is honored for agenda/schedule and ignored for sessions; every link and every search form inside an embed targets /e/:slug/... full-chrome pages. A parameter that parses and then does nothing is the same lie as a cap the UI cannot see. The path helpers in shell.tsx take an explicit base, the dispatch threads whether it is rendering an embed, and getSurfaceFeedPage applies the same CardFields projection the HTML dispatch applies.
