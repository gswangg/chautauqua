# DEC-647: A closed two-list is closed in BOTH directions: every pubcache pattern matches a real route, and no path matches both lists

DEC-627's scan proves every registered mutating route matches one of the two purge lists; nothing proves the converse. A pattern that matches no route is invisible in both failure modes: a typo silently means "this route bumps" (the fail-safe default, so no test notices) and a stale NEVER_PUBLIC entry silently suppresses the bump for whatever route is later registered at that path — the exact class of bug DEC-627 exists to prevent. This is the rule DEC-637 applied to the API reference, applied to the purge lists: enumerate both ways, and assert disjointness so no path is classified twice.
