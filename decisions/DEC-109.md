# DEC-109: Portal edit: stored file-kind answers are merged into the extracted answer map and file-kind required is forced false during validation; file values written back unchanged

extractAnswers (src/routes/portal/edit.tsx:56-60) skips file-kind fields without merging the stored answer back, so validateAnswers (src/forms/validate.ts:38) flags any visible required file field as 'required' and every save 400s — bricking J2/CFP-06 ('accepted speakers keep editing') for any CFP form with a required upload. Ruling: (1) extractAnswers takes the stored AnswerMap and copies each file-kind field's stored value into the extracted map when present (preserving visibility-rule inputs); (2) the POST handler validates against a mapped field list where file-kind fields have required forced to false (file fields are read-only on this surface, per DEC-041, so their absence must never be fatal); (3) carried-over file values flow through cleaned and saveSubmissionEdits harmlessly rewrites the identical value — untouched answer rows are preserved because saveSubmissionEdits only upserts entries present in cleaned. validateAnswers itself is UNCHANGED: public submit still enforces required file fields.
