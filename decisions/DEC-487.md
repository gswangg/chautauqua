# DEC-487: The three public paging constants live together in src/server/repo/public/bounds.ts, and hasMore is a shared predicate beside them

DEC-477 requires MAX_PUBLIC_ROWS to be derived from MAX_PUBLIC_PAGE x the public page size so that editing either fails a test instead of silently shadowing the other. Today those three numbers live in three files across two layers: PER_PAGE=12 in src/routes/public/shell.tsx:20 (a JSX/CSS module), MAX_PUBLIC_PAGE=50 in src/routes/public/query.ts:10, MAX_PUBLIC_ROWS=600 in src/server/repo/public/bounds.ts:9. A repo module may not import a routes module, so the derivation can only live at the repo layer — bounds.ts becomes the one home (PUBLIC_PER_PAGE, MAX_PUBLIC_PAGE, MAX_PUBLIC_ROWS = MAX_PUBLIC_PAGE * PUBLIC_PER_PAGE) and the routes import from it. The old declarations are deleted outright, not re-exported (house rule: no compatibility re-exports). hasMorePages(shown, total, page, perPage) lives there too, because DEC-477's second half — Show-more must stop at the ROW ceiling as well as the page ceiling, which an ?limit=100 embed reaches first — is a rule about those constants and is currently duplicated three times (src/routes/public/sessions.tsx:25, speakers.tsx:35 and :96) in a form that only tests the page bound.


## Amendment (wave 10, sha e770146d): a public query knob's RANGE is a declared constant in bounds.ts, and its refusal sentence is composed from that constant

bounds.ts states in its own header that it is "the ONE home for every public-surface paging constant", yet the embed `limit` knob's 1..100 range is hand-typed twice and in two different forms: as a bare numeric comparison in parseLimit (src/routes/public/query.ts:80) and as English prose in an ApiError message (src/routes/api/embeds.ts:140). test/text-cap-declaration.scan.test.ts has been carrying that second copy in a live allowlist whose own reason calls it "a real finding" and then defers it to "a follow-up wave" — a schedule-shaped exemption, which DEC-099/DEC-518 already ban as a reason. RULING: MIN_EMBED_LIMIT/MAX_EMBED_LIMIT are declared in src/server/repo/public/bounds.ts beside PUBLIC_PER_PAGE/MAX_PUBLIC_PAGE; parseLimit and the API refusal both read them; the allowlist empties. A bound the product enforces and a bound the product describes must be the same symbol.
