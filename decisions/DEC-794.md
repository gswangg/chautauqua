# DEC-794: Arming a placement never moves the grid, and the target you must hit is never buried

USER-REPORTED, VERIFIED in app/src/pages/agenda/DayGrid.tsx: (a) :115 showTbdColumn = dayHasNullRoom || armed !== null appends a whole grid column on arm, and the template at :231 is 80px repeat(n, minmax(140px,1fr)), so every column reflows the moment a session is armed — plus the "Placing… Esc to cancel" banner pushes the grid down; (b) the merged clash card (:346-389) is painted after the cell buttons in the same grid area, so in placing mode the inverted-ink card visually buries exactly the occupied-slot buttons where place-anyway matters (the click itself works — DEC-701/769 — it is the target that is invisible). Decision: geometry is INVARIANT across arm/disarm. The room-less column's membership depends only on the day's data (a room-less placement exists), never on `armed`; while armed, the no-room target is offered as one full-width strip BELOW the grid, which keeps the capability without touching column widths. The placing banner's height is reserved at all times (the element is always laid out; only its content and accessibility exposure change). While armed the grid carries a state class that lifts cell buttons above placed/clash cards with a visible outline legible on ink and quiets the clash card, so the target set is the whole grid, not whatever the cards left visible.
