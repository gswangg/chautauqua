# DEC-806: /admin resolves to /admin/overview

VERIFIED app/src/App.tsx:267 renders <Route path="/" element={<OverviewPage />} /> — so landing on /admin shows Overview's content at a URL that is not Overview's route, and the nav item, whose active state is derived from the path, never lights up on the one screen every organiser starts from. This is the same class as the earlier trailing-slash highlight bug and has the same fix. Decision: '/' redirects (replace, so Back still leaves the app rather than bouncing) to '/overview'; RoleGate keeps wrapping the routed region, so a reviewer landing on /admin is still bounced to /review before the redirect is ever considered. Position is re-derived from the URL — a page that renders without owning its URL cannot be linked, badged, or highlighted.
