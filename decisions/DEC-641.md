# DEC-641: Sessionboard layer 2 (the REST-API adapter) closes as a documented stage-1 non-goal, with its reason

steal-mandate §5 asks for it "labelled honestly", but we have no account, so not one byte of it can be executed, and its own stated value is credibility. A token field wired to unverifiable paging code behind a real-looking UI is precisely the "simulator behind a full UI" the same mandate warns against — the honest artefact is the sentence saying we did not build it and why. Layer 1 (export import, dry run, idempotent external_ref upsert, now including participants) is the differentiator a judge can actually exercise. Recorded as a non-goal in docs/AUDIT.md and README, never as "coming soon".
