# DEC-220: POST /api/v1/users/:id/reset-password has no self-target guard: any own-org user id, including the caller's own, is a valid target

DEC-215 grants reset power over reviewer and organizer accounts on intra-org trust (mirroring DEC-043 create power). Excluding the caller's own id would add a special case with no security benefit — self-reset merely revokes your own sessions and returns a password you already control — and would complicate the stranded-co-organizer recovery path the endpoint exists for. Plain reading: 404 only for unknown/cross-org ids, no other target restrictions.
