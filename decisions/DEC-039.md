# DEC-039: Reviewer-surface org scoping: organizers resolve plans only via getPlanForOrg

Cross-org IDOR confirmed: requireAssignedPlan (review.ts:344) returns any plan to any organizer via un-scoped getPlanById, and the organizer branch of GET /api/v1/review/plans (review.ts:328) lists plans for an arbitrary eventId — violating SPEC §6 object-level ownership. Binding rule: on /api/v1/review/*, organizers resolve plans exclusively through repo.getPlanForOrg(db, planId, auth.orgId) (the same helper the producer endpoints already use); the plans list requires an eventId verified to belong to auth.orgId before listing; reviewers continue via plan_reviewer assignment with not_found on miss. Un-scoped getPlanById must not appear in any route handler.
