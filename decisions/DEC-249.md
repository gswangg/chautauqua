# DEC-249: Format-column auto-show matches a fixed label allowlist {'format', 'session format'} (amends DEC-243)

w2-e CFP-06a: DEC-243 specified an exact case-insensitive match on the label 'Format', but the vendored fixture/seed form labels its dropdown 'Session format' (scripts/seed.ts:367), so findFormatField (app/src/pages/submissions/columns.ts:46) never fires on real data — the mechanism is implemented but unreachable, and it has zero unit tests. Resolution: widen to a fixed two-entry case-insensitive allowlist — trimmed lowercase label === 'format' OR 'session format'. Deterministic exact matching is preserved (no substring/fuzzy rules that could catch unrelated fields like 'Reimbursement format'), and the fixtures stay untouched (relabeling seed data to fit the code would be fixture-gaming; the product adapts to the data, not vice versa).
