# DEC-817: A field accepts exactly the value its own placeholder shows

VERIFIED the embed builder's Accent color input (app/src/pages/settings/EmbedsPanel.tsx:289) placeholders `#4E5C31` and drops what you type straight into the embed URL's ?accent=, where parseAccent (src/routes/public/query.ts:74) requires 3- or 6-digit hex WITHOUT '#' and returns null for anything else — so copying the placeholder produces an embed with no accent and no error anywhere. DEC-793 settled this rule for the composer; this is the same rule one field over, and the general lesson is that a builder's parameter set and the live route's parsers are ONE contract that must be checked by enumeration, not by reading two files. Decision: parseAccent tolerates one optional leading '#' and still normalizes to '#rrggbb' (the value remains validated and never interpolated raw — DEC-374 untouched), and a parity test enumerates EVERY parameter the builder can emit against the parser the live route runs, so a future builder field the route ignores fails a test instead of a visitor.

## Amendment (findings wave 13): the admin SPA and its routes are ONE contract, graded executably — every key the SPA sends is a key some route parses

DEC-817 made the embed builder and the live public route one contract by enumerating every parameter the builder can emit from the builder's own constant arrays and round-tripping each through the parser the live route runs. The admin SPA has the same seam and no such grader, and it has now failed twice in the same file (DEC-900 amendment above): two controls that POST/PATCH a key no route reads, shipped, reviewed and swept past for waves, because nothing anywhere compares the two sides. Both defects are a one-line grep apart from being impossible. RULING: the parity is executable and lives in test/, derived from the SPA's own source rather than a hand-written list — every literal-object body passed to apiPost/apiPatch/apiPut under app/src/ contributes its top-level keys, each request path is resolved to the route module that serves it, and every key must appear in that module. Unresolvable paths fail loudly (a path the resolver cannot map is a gap in the grader, not a pass), and the shape is a SCAN with no allowlist for known-open keys — an allowlist would be the cap nobody is told about.
