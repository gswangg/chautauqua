# DEC-762: The field-kind vocabulary the organiser reads is the mock's, defined once; and a public link is disclosed exactly once per screen

app/src/pages/forms/types.ts:55 labels a dropdown field "Dropdown" and FieldModal.tsx:86 repeats the word in its error copy, while the design pack names the same kind by what the submitter does with it — "Single choice". Hand-copied vocabularies drift (field guide), so the organiser-facing labels live in one exported map that the row list, the modal and every error string import; the stored kind strings do not change, because the wire vocabulary and the reading vocabulary are different concerns. Likewise the builder currently discloses the form's public URL twice — FormsPage.tsx:276's fields-section footer (which the mock draws) and a second block inside FormSettings.tsx:224 — and two copies of one URL invite the reader to wonder which is authoritative; the footer row is the one disclosure. Row captions come from a field's own help text when it has one, never from per-row literals invented to match a screenshot.
