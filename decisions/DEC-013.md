# DEC-013: API conventions for /api/v1 and the SPA client contract

The SPA table task and the API tasks are opposite sides of the same wire and run in parallel, so the shapes are fixed here. JSON only; timestamps are ms-epoch numbers matching DEC-003. List endpoints accept ?page (1-based), ?perPage (default 50, max 200 — server-clamped), ?q, plus per-resource filters, and return { items, total, page, perPage }. Errors: non-2xx bodies are { error: { code, message, fields? } } with codes 'unauthorized' (401), 'forbidden' (403), 'not_found' (404), 'invalid' (400, validation details in error.fields as Record<field,message>), 'conflict' (409); unexpected exceptions propagate to a 500 with code 'internal' — fail loudly, no swallowing. Session-authenticated mutations require the x-chq-csrf header (DEC-004); bearer tokens are deferred to the J12 wave (needs an api_token table via DEC-015 discipline). Admin API endpoints are organizer-only by default; reviewer- and speaker-accessible endpoints are explicit, narrower routes. The SPA consumes the API exclusively through app/src/lib/api.ts: fetch with credentials 'include', sets x-chq-csrf on mutations, unwraps the list envelope, and throws a typed ApiError on any error envelope.

## Amendment (wave 54): clampPage has an upper bound — a page param is clamped, never trusted into an offset

clampPage (src/lib/pagination.ts:13-17) enforces only `n >= 1`, so `?page=1e21` passes Number.isInteger and `(page-1)*perPage` reaches `.offset()` on every admin list (views.ts:45, submissions/query.ts:134, email.ts:181, files, comments) as a non-safe-integer float — an unhandled input class that 500s instead of answering. The public side already solved this: parsePage clamps to MAX_PUBLIC_PAGE (src/routes/public/query.ts:26) rather than rejecting, and clampPerPage's own contract is clamp-not-throw. Rule: pagination.ts exports MAX_PAGE and clampPage clamps to it, keeping the pure-core rule (no ApiError import in src/lib) and keeping one shape across public and admin; the invariant the tests assert is that `(clampPage(x)-1)*clampPerPage(y)` is always a safe integer for ANY input.
