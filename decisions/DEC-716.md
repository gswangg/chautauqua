# DEC-716: The sign-in page names the event when there is exactly one, and offers the open call for papers as the only onward action -- suppressed when none is open

Login is the first screen every judge and organizer sees, and it currently says only 'Sign in to your account' with no route for a person who has no account. The hub already computes the deployment's public events and their CFP state (listHubEvents + groupHubEvents); reusing them rather than re-querying keeps one definition of 'a live event' and one of 'the CFP is open'. The block is strictly conditional: with exactly one hub event the subheading names it, with exactly one open CFP the 'No account?' block links to it, and with none open the block does not render at all -- a dead 'submit a talk' link is worse than no link.
