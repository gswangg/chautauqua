# DEC-653: The SPA has no second upload vocabulary: delete the mirror, import the pure core

app/src/pages/content/upload-validation.ts hand-copies the DEC-020 allowlist and caps, and it is ALREADY WRONG: it caps .txt/.md at 8 MB (TEXT_MAX_BYTES = MEDIA_MAX_BYTES, line 16) while the server authority allows 25 MB (src/domain/files.ts:50), so a 12 MB .md is rejected in the browser with a message the server disagrees with — silent capability loss plus a false explanation. src/domain/files.ts even exports ALLOWED_UPLOAD_EXTENSIONS documented as "for UI hints (accept attr, help text)" with no consumer, and the file input carries no `accept` at all. DEC-002 made pure-core node/cf-free precisely so a browser bundle could share it; app/src/pages/content/types.ts re-declaring 'presentation'|'poster'|'handout' is the same duplication. Delete both copies (no compat shim, house rule) and import FILE_KINDS / validateUpload / uploadHintText / ALLOWED_UPLOAD_EXTENSIONS directly. Hand-copied vocabularies drift — IMPORT them.
