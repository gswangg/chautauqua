# DEC-816: Each public surface's count is the set that surface actually renders

VERIFIED GET /events/:eventId/public-surfaces already returns three separate numbers — sessions, speakers, scheduled — precisely because the surfaces answer different predicates (DEC-767), yet app/src/pages/settings/PublicPagesPanel.tsx:103-104 spends `sessions` on both the Agenda and Schedule rows and never reads `scheduled` at all. Those two surfaces render only PLACED sessions, so the row can say 'Live · 16 published' over a page a visitor sees showing 9 — the exact count-versus-list drift the field guide already names. Decision: agenda and schedule read counts.scheduled; sessions reads sessions; speakers and gallery read speakers. One predicate per surface, the same one its SSR page composes, asserted row by row in the panel's test rather than trusted.
