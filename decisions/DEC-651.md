# DEC-651: One dialog HEADER contract: title + optional subtitle + Close, primary action first, and every free-text control in a dialog carries the mock's placeholder — enforced by a source scan, not by habit

The ONE dialog contract already fixes the scrim, role=dialog/aria-modal and Escape, but stops at the frame: NewSubmissionModal renders a bare `<h2>`, no Close, `Description` where the mock says `Abstract`, Cancel before the primary, and not one placeholder — while the mocks specify placeholder text in every field of every modal. 26 placeholder occurrences exist across 18 of ~50 form-bearing components. A hand-audited copy pass drifts back the moment a modal is added, so the contract becomes a scan over the files that contain role="dialog": each must carry `.chq-modal-title` and a Close control, and each `chq-input`/`chq-textarea` in those files must carry a placeholder. The contract is MARKUP, so a hand-written dialog and a ModalFrame-rendered one both satisfy it.
