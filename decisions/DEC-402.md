# DEC-402: Every `<table className="chq-table">` in the admin SPA carries a page-prefixed class, and the import preview table gets the phone card it never had

app/src/pages/contacts/ImportWizard.tsx:197 renders a four-column Email/First/Last/Company table with no page-prefixed class, so no page stylesheet can address it: contacts-panels.css's 700px block converts `.chq-contacts-import-mapping` to cards and leaves this one as a real table full of unbreakable email addresses at 390px. It is invisible to every gate because it only exists after a CSV upload, which the sweep cannot reach. The two settings tables (ExportsPanel.tsx:27, ApiTokensPanel.tsx:103) are covered today only by settings.css's descendant rule `.chq-settings-panel .chq-table` — that works, but it means a table's phone behaviour depends on an ancestor nobody names. Rule: the second class is mandatory and checkable by a source guard; the descendant rules that already work stay as they are. This is the cheap, mechanical half of phone conformance — the measured half is DEC-401.

## Amendment (wave 20): the table guard binds the ELEMENT, not one spelling of its class attribute

test/table-class-conformance.test.ts matches `/className="chq-table([^"]*)"/` -- it sees a table only when chq-table is the FIRST token of a double-quoted literal. A `className={...}` expression, a single-quoted attribute, or a class list where chq-table is not first is invisible, and the file's only tripwire counts scanned FILES (>= 1), not matched call sites, so the guard would report green over an empty match set. That is exactly wave 19's finding (GUARD THAT MATCHES ONE SPELLING OF className MEASURES NOTHING) living in a second file. Ruling: the guard enumerates every `<table` JSX element under app/src (non-test .tsx), the way test/control-class-conformance.test.ts already enumerates control elements, and each element must carry `chq-table` plus a page-prefixed second class as a STATIC string literal -- a computed className on a table is itself the violation, reported by name, because a guard cannot read what it cannot see. A match-count tripwire (>= 12 table elements) replaces the file-count one.
