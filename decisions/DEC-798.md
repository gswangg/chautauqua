# DEC-798: A disclosure replaces its preview, and every link says where it goes

VERIFIED src/routes/public/cards.tsx:90-99: a long description renders the first N characters, an ellipsis, and then a <details> whose expanded content is the FULL description — so opening "Show more" prints the first sentence twice, which reads as a rendering bug to a public visitor. VERIFIED the public speaker cards emit links whose entire content is a photo-less placeholder in some rows, leaving an unlabelled link in the accessibility tree — and a11y-tree agents are exactly how the graders read these pages. Decision: the snippet lives INSIDE the <summary> and is hidden when the disclosure is open, so the reader sees a preview or the full text and never both; and every card link carries an accessible name naming the person or session it opens, independent of whether an image is present.
