# DEC-621: Comms on a phone lands on a choice, and no input may clip the text it holds

The first phone screen of Comms is a landing that names the three things it can do (Compose, Templates, History) rather than dropping the user into step 1 of the compose wizard, and the step bar's labels must not stack one letter per line. Separately: a text input inside a grid or flex parent defaults to min-width:auto and will clip its own value — the fix is one rule in the comms stylesheet covering the template Subject/Name inputs, not a per-input patch, because one stylesheet per layer owns its bare controls.
