# DEC-911: There is one public 404 and it is the designed card — a bare c.text is an undesigned second 404

src/routes/public/index.tsx routes every unknown /e/:slug through publicNotFound (src/routes/public/not-found.tsx), which renders the designed PublicNotFoundShell and carries DEC-297's no-cache contract. src/routes/public/submit.tsx:116/172/267 does not: an unknown slug on the CFP surface returns `c.text('Event not found.', 404)` — a bare plain-text body, no shell, no branding, no cache header discipline — and :118/174/269 does the same for 'This event is not accepting submissions yet.', which is a real, expected, designed state (the frames draw a closed-CFP page) being served as an error string. A visitor arriving from a stale conference link meets the ugliest page in the product. Rule: no public route emits a text/plain 404; every one goes through publicNotFound so the shell, the status and the cache headers come from one place. The 'not accepting submissions yet' case renders the SAME designed shell with its own message rather than inventing a second chrome — one card, two sentences, not two cards.
