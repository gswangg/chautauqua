# DEC-733: An action that cannot apply to a row is ABSENT, not disabled — and a library states only endpoint-backed figures

Conditional-and-quiet is the design's affordance rule (it is why the Response link and per-person Remind are conditional). Content violates it: Approve renders on already-approved rows, and undocumented Deliverables/Headshots tabs sit half-built. A disabled control is a promise the app will not keep; delete it or make it real. The files library's stat line and deliverable chips must come from the list endpoint's own counts (never a client-side count of the current page), and 'Download all' must be backed by the existing zip path rather than a decorative button.
