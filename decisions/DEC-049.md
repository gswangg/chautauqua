# DEC-049: /admin served through the Worker (ASSETS binding + run_worker_first) with role redirects; GET / is an SSR landing

Static asset serving means /admin deep links 404 on refresh, and SPEC §6 requires speakers hitting /admin to be redirected — which must happen server-side. wrangler.jsonc assets gain "binding": "ASSETS" and "run_worker_first": ["/admin", "/admin/*"]; a new src/routes/root.tsx proxies /admin/assets/* to ASSETS, and for all other /admin paths: anonymous → 302 /login, speaker → 302 /portal, organizer/reviewer → ASSETS-fetched /admin/index.html. GET / renders a small SSR landing linking /admin, /portal, the seeded event's /submit and /e/<slug>/sessions, plus /dev/mailbox when DEV_MODE — the root URL never 404s for a judge.
