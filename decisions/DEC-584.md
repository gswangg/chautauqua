# DEC-584: The public agenda at phone width is a SECOND markup, not a reflowed grid — and duplicated itinerary checkboxes must mirror each other or unchecking silently fails

AgendaDayGrid is an absolutely-positioned CSS grid whose columns are rooms; at 390px there is no reflow that turns it into a readable list, which is why the surface is still a raw horizontally-scrolling grid on a phone. SSR cannot know the viewport, so the only honest answer is to emit both markups from one payload and switch at the 700px breakpoint with display:none — which, unlike visibility/opacity, also removes the hidden copy from the accessibility tree, so a screen reader never hears the day twice. The consequence must be handled deliberately: each session then renders TWO .chq-itinerary-toggle inputs with the same value, and the existing inline script computes its selection as 'every checked box', so unchecking the visible copy leaves the hidden copy checked and the removal never persists — a silent data-loss-shaped bug introduced by the fix itself. The change handler must therefore set every input sharing that value to the new checked state before recomputing, and the rendered-id list must be deduped before it reaches mergeItinerarySelection.

## Amendment (wave 64): the public agenda's DESKTOP render is a time-row SEQUENCE, not a room-lane matrix

Verified on main: src/routes/public/agenda.tsx:104-120 still renders `grid-template-columns: 70px repeat(rooms, ...)` with room column headers and an hour-tick gutter — the organiser-density idiom the vendored v7 handoff (docs/design/README.md, "Public agenda — desktop") explicitly replaced. At public density (<=10 sessions/day over 1-4 rooms) lanes spend most of their pixels on nothing and the day gets drawn three times. RULING: one row per distinct start time — an 88px time cell (rendered ONLY where something starts) plus the sessions starting then, laid out `repeat(auto-fit, minmax(228px, 1fr))`; room becomes an eyebrow LABEL on the block, never a column header; the day appears ONCE in the heading ("Tuesday 12 May · N sessions · M rooms"); a break is a full-width spanning quiet rule with a small-caps label, never a block; no clash indicators (clashes are an organiser concept). DEC-584's actual subject — two markups from one payload, switched at 700px, with mirrored itinerary checkboxes — is UNCHANGED: the phone list and the mirroring rule stay exactly as they are, because mobile is deferred. The block element keeps the class `chq-pub-agenda-block` (ACCENT_BOUND_CLASSES, public.css.ts:31).
