# DEC-591: The seed has ONE clock: every seeded instant is an offset from SEED_NOW, and the demo shows a day's work rather than a backlog

scripts/seed.ts currently anchors on BASE_TS = 2027-01-15 with CFP close 2027-03-01 and task due dates derived from eventStartMs (2027-04-07..05-05). Against a real clock of 2026-08 that makes every created_at row sit in the future, every onboarding task un-overdue, and every countdown ~200 days out — the design README §Open decisions calls this out as the one unresolved data question. Fix it at the source: SEED_NOW = Date.now() (overridable by env CHQ_SEED_NOW as an ISO instant so a build can be reproduced), row timestamps start ~120 days behind it, the CFP closes ~18 days ahead of it, the evaluation plan window straddles it, and onboarding due dates are SEED_NOW offsets with three already past. The event's own dates stay absolute (2027-05-12..14) because the fixture's event NAME says 2027 and docs/fixtures is vendored — so the seed must assert loudly that SEED_NOW is comfortably before event start rather than silently emitting a conference that already happened. One clock also means one honest Overview: the headline count equals the rows the page renders, and each section stays small enough to read as a to-do list.
