# DEC-453: A completion ledger may not grade a measured budget from code presence, and must re-read every evidence log that landed after the previous ledger's sha

task-w16-f-spec-audit-stage1.md returned RESULT: PASS with both lists empty at S = 235d677 while an unowned FAIL sat on main: task-w16-c-perf-smoke-stage1.md ends OPEN ITEMS: 1 / RESULT: FAIL on the reviewer-queue budget and merged after S. The ledger graded SPEC §7's read budget 'VERIFIED (mechanism)' by citing the perf harness and asserting the two prior open items were closed from the presence of DEC-439's code -- exactly the inference the measurement refuted. Two rules follow. (i) A SPEC row whose bar is a measured number may only be graded from a perf-smoke run whose sha is an ancestor-or-equal of the ledger's own S; code presence proves a fix was attempted, never that a budget is met. (ii) A ledger must enumerate every stage-1 evidence log that landed since the previous ledger's sha and reconcile each one's RESULT and OPEN ITEMS against its own S; a log it cannot see is a reason to move its cut, not a reason to omit the row. DEC-447's ordering therefore extends: a closing wave's ledger is cut behind that wave's evidence lanes, not only behind its source lane.

## Amendment (wave 28): a gate lane MAY repair its own instrument before the measured run, and a ledger grades a lane it cannot see as PENDING-OWNED, never as absent

DEC-453 bars a ledger from grading a measured budget on code presence and requires it to reconcile every evidence log landing after the previous ledger's sha; the corollary the swarm has been reading into it — that a gate which fixes what it finds cannot report on the sha it measured — is correct for a gate that repairs the PRODUCT mid-run, and wrong for a lane that repairs the INSTRUMENT before running it. Two rules follow. (i) An instrument repair committed BEFORE the measured run is not 'fixing what the gate found' — the gate had not run yet, and running a knowingly-false assertion to preserve lane purity produces a FAIL that measures nothing (task-w26-f's 'version 2' is precisely that). Such a lane reports, and its receipt names BOTH shas: the product sha it measured and its own instrument-repair commit, so a reader can tell what changed under the measurement. The repaired instrument's first run is QUALIFYING under DEC-069's wave-28 amendment. (ii) Wave 28's ledger lane runs concurrently with its gate lanes and will not see their sections on its own frozen sha. It must therefore read .git/refs/heads/* for ownership (DEC-069 wave-17 amendment) and grade a required gate section whose lane has a live branch as PENDING-OWNED(<branch>) — never as PASS by inference, never as a missing row, and never as FAIL-unowned. FAIL-unowned is reserved for a required section with no branch anywhere claiming it. This keeps the ledger honest in a parallel swarm without inventing a serialization the wave does not have.

## Amendment (wave 40): the battery files, it does not fix — and the perf lane's RECIPE-BLOCKED fallback lives in local D1 only

A lane that fixes what it measures cannot report on the sha it measured. A measurement-only local fixup is not a fix of the thing being measured; committing one would be.

## Amendment (wave 42): a frozen adjudication lane FILES, never fixes — and may add a green test only for behaviour it rules DELIBERATE

A lane that fixes what it measures cannot report on the sha it measured, and in a frozen wave a fix additionally voids four PASS gate sections. Every wave-42 adjudication lane therefore classifies each claim as CONFIRMED-DEFECT (quoted file:line + the minimal fix direction + a named wave-43 owner, NOT implemented), DELIBERATE-BY-DESIGN (citing the binding DEC), RULED-NOT-A-DEFECT (with reasoning), or STALE (fixed in-tree, with the file:line proving it). Second half of the rule, because it is the failure mode a test-writing frozen lane actually hits: a lane may add a GREEN test under `test/**` only for behaviour it ruled DELIBERATE-BY-DESIGN — a characterization test written over a CONFIRMED-DEFECT entrenches the defect and converts a finding into a contract. Confirmed defects get prose and an owner, never a test.
