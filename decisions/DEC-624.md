# DEC-624: Anonymity is a ratchet: it can be granted, never revoked once evaluations exist under it

anonymized is read live from the plan (DEC-596), so an organiser toggling it off retroactively unmasks reviewers who wrote under a promise of anonymity. steal-mandate §2 asks for an assignment-time snapshot; that would need an additive migration and a second source of truth for a flag DEC-596 already says the plan owns. The monotone rule delivers the same integrity property with no schema change and no second truth: turning anonymity ON is always allowed; turning it OFF is refused with a 409 naming the count once any evaluation has been submitted under that plan. Fail closed, and never silently.
