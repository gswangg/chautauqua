# DEC-637: The API reference is enumerated from the router, not maintained by hand

/docs/api is the public face of J12 'the data stays theirs', and its route table is a hand-written array checked by four spot assertions. Hand-listed manifests desync — that lesson is already law here for the seed wipe list (DEC-518 style) and for AUDIT.md (DEC-618); the API reference is the same shape and has no guard. Decision: the mounted app exports its Hono instance, the docs module exports its sections, and a test walks app.routes to assert both directions over /api/v1 — every registered route is documented and every documented row exists — with an explicit, reasoned allowlist for anything deliberately undocumented and a floor count so an empty scan cannot pass.
