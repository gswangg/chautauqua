# DEC-378: One backdrop and one dismissal contract for every SPA dialog: .chq-scrim wraps .chq-modal, Escape closes, the two legacy backdrop classes are deleted

Verified on main, the SPA carries three different backdrop conventions and no dismissal behaviour at all: `.chq-modal-overlay` (EventSwitcher, NewSubmissionModal, FieldModal, TaskModal, ResponseModal), `.chq-modal-backdrop` (DuplicatesView, ImportWizard, PipelineBoard x2) and `.chq-scrim` (AddToEventModal, BulkEmailModal, ContactDrawer) — and only the third is defined in any stylesheet, so seven dialogs render today with no backdrop over live page content, and `.chq-modal` is itself `position: fixed; inset: 0` so it is styled as a standalone panel rather than a scrim child. Canonical contract: `.chq-scrim` is the ONLY backdrop (a fixed flex container, ink at 50%), `.chq-modal` is its static child, `.chq-modal-overlay` and `.chq-modal-backdrop` are deleted with their call sites (no aliases kept — house rule forbids compatibility shims). Every dialog carries `role="dialog"`, `aria-modal="true"` and an accessible name; Escape closes it; a click on the scrim itself (`e.target === e.currentTarget`) closes it only when a cancel path is non-destructive and no mutation is pending. The keyboard half is one shared hook, `app/src/lib/useEscapeKey.ts`, whose source is fixed here verbatim so two lanes may create it independently without diverging: `import { useEffect } from 'react'; export function useEscapeKey(active: boolean, onEscape: () => void): void { useEffect(() => { if (!active) return; function onKeyDown(e: KeyboardEvent) { if (e.key === 'Escape') onEscape(); } window.addEventListener('keydown', onKeyDown); return () => window.removeEventListener('keydown', onKeyDown); }, [active, onEscape]); }`. No focus trap is added: it is not required by the handoff's AA bar and a half-built trap is worse than none.
