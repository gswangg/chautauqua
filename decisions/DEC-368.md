# DEC-368: CSS file ownership: one shared stylesheet owned by the shell lane, co-located page stylesheets owned by page lanes

Ten lanes re-skinning ten screens in parallel would otherwise all edit app/src/styles.css and collide on every merge. Rule: app/src/styles.css is owned EXCLUSIVELY by the shell lane and is the only place the SPA's shared classes are defined — .chq-shell, .chq-header, .chq-wordmark, .chq-nav, .chq-nav-link (+.is-active), .chq-nav-badge, .chq-tabbar, .chq-main, .chq-measure, .chq-page-title, .chq-summary, .chq-toolbar, .chq-section, .chq-section-head, .chq-section-label, .chq-section-action, .chq-row, .chq-row-title, .chq-meta, .chq-flag, .chq-btn with .chq-btn-primary/.chq-btn-secondary/.chq-btn-tertiary, .chq-input/.chq-select/.chq-textarea/.chq-check, .chq-table, .chq-pill, .chq-chipstrip, .chq-modal, .chq-drawer, .chq-deadlines, .chq-empty, .chq-error. Every other lane adds a co-located stylesheet imported by its page module (e.g. app/src/pages/submissions/submissions.css imported from Submissions.tsx, exactly as app/src/main.tsx imports styles.css) and may only define classes prefixed .chq-<area>-*; redefining or overriding a shared class in a page stylesheet is forbidden — if a shared class is wrong, the shell lane fixes it next wave. Page CSS rides the page's existing React.lazy chunk (DEC-052), so it costs nothing on first paint and keeps the <300KB gz entry budget. Lanes may use shared class names before the shell lane's definitions land; the merge resolves them.


## Amendment (wave 83, v12 mobile campaign w1): at 390 a card-stacking table gives its edge inset back to the page gutter

`.chq-table th:first-child/td:first-child{padding-left:16px}` and the `:last-child` mirror (app/src/styles.css:903-911) exist so content never touches a hover/selection fill's edge on desktop (DEVIATIONS §2, user-filed). At 390 every such table stacks into cards inside .chq-main's own 16px phone gutter (styles.css:416), so the two insets add to 32px and card text sits a quarter-inch off the frames' 16px line. comms.css:1399-1408 neutralised its own two tables locally; the rule is global so the fix is global. Ruling: zero the first/last-cell inset inside the shared phone block, and let any page that still renders real columns at 390 restore it in its own stylesheet. This is a shell-owned shared class, so only the shell lane may make the change (DEC-368's ownership rule).


## Amendment (wave 84, v12 mobile campaign w2): One frame demanding a smaller row title buys a page-local override, not a re-cut of the shared class

`docs/design/audit/speakers-v12.md` finding 3: the speakers grid's name link is 16px in frame `Chautauqua Speakers.dc.html:129` and 18px in the app, because it renders through the shared `.chq-row-title` (app/src/styles.css:559). The audit correctly refused to touch a shell-owned file and left the reconciliation open. The tempting move — re-cut `.chq-row-title` to 16px — would silently move the row title on every table in the product on the strength of ONE frame, which is the shared-class version of a hand-listed population standing in for a real one, and it would break the desktop freeze on surfaces whose own v12 frames were never measured. Ruling: the speakers grid gets a page-local 16px override in `app/src/pages/speakers/speakers.css` scoped to the grid's name link, and the shared `.chq-row-title` stays 18px until the whole population of row titles is measured against its frames. That measurement is Tier 2 sweep work (density pairing / type-role audit), not this wave's. This keeps DEC-368's ownership rule intact — page lanes change page stylesheets, the shell lane changes the shared one — and it means a later sweep that DOES re-cut the shared class will find exactly one page-local override to delete rather than a silent global change to reverse.
