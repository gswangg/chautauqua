# DEC-368: CSS file ownership: one shared stylesheet owned by the shell lane, co-located page stylesheets owned by page lanes

Ten lanes re-skinning ten screens in parallel would otherwise all edit app/src/styles.css and collide on every merge. Rule: app/src/styles.css is owned EXCLUSIVELY by the shell lane and is the only place the SPA's shared classes are defined — .chq-shell, .chq-header, .chq-wordmark, .chq-nav, .chq-nav-link (+.is-active), .chq-nav-badge, .chq-tabbar, .chq-main, .chq-measure, .chq-page-title, .chq-summary, .chq-toolbar, .chq-section, .chq-section-head, .chq-section-label, .chq-section-action, .chq-row, .chq-row-title, .chq-meta, .chq-flag, .chq-btn with .chq-btn-primary/.chq-btn-secondary/.chq-btn-tertiary, .chq-input/.chq-select/.chq-textarea/.chq-check, .chq-table, .chq-pill, .chq-chipstrip, .chq-modal, .chq-drawer, .chq-deadlines, .chq-empty, .chq-error. Every other lane adds a co-located stylesheet imported by its page module (e.g. app/src/pages/submissions/submissions.css imported from Submissions.tsx, exactly as app/src/main.tsx imports styles.css) and may only define classes prefixed .chq-<area>-*; redefining or overriding a shared class in a page stylesheet is forbidden — if a shared class is wrong, the shell lane fixes it next wave. Page CSS rides the page's existing React.lazy chunk (DEC-052), so it costs nothing on first paint and keeps the <300KB gz entry budget. Lanes may use shared class names before the shell lane's definitions land; the merge resolves them.
