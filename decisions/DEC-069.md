Six verification lanes have now run (five dropped, one green pre-merge) with no objective way to say 'done'. Fix: stage-1 completion is declared only when docs/verification-log.md on main contains, at or after the newest code-bearing main sha, four gate sections — build+test, J1-J12 walkthrough vs seeded wrangler dev, perf smoke, SPEC §8/§9 static audit — each ending with exactly one line 'RESULT: PASS' (or 'RESULT: FAIL — <summary>' when failing), plus a triage-closure section ending 'OPEN ITEMS: <n>' with n=0.
