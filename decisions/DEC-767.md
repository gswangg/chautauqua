# DEC-767: A public surface's published count is the number that surface's own query returns

VERIFIED: app/src/pages/settings/PublicPagesPanel.tsx:70 counts accepted submissions and prints it as "Live · N published" on all five surfaces -- including Speakers and Gallery, which publish PEOPLE, not sessions. The EMB probe read 16 where the public site showed 9. SPEC J10's guarantee is "widgets read the same tables as admin -- consistency by construction", and the gates are deliberately distinct (accepted AND participant.visible AND content approved). Decision: one organizer endpoint returns per-surface counts composed from the SAME predicates the SSR surfaces use (src/server/repo/public/gates.ts) -- sessions/agenda/schedule report publicly visible sessions, speakers/gallery report publicly visible speakers -- and the panel renders those numbers. A number on a settings row is a promise about what a visitor will see; it must be produced by the query that visitor runs.
