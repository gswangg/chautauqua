# DEC-057: Public-submit rate limiting migrates to the DEC-038 scoped limiter; submit-core's legacy limiter is deleted

DEC-038 made src/lib/rate-limit.ts the canonical scoped KV limiter but froze submit-core's older copy; keeping two limiters violates the no-compat-shims house rule and invites drift. checkAndIncrementScopedLimit(kv, 'submit', ip, now, {windowSeconds: 3600, max: 10}) produces byte-identical KV keys to the legacy rateLimitKey ('ratelimit:submit:<ip>:<windowStart>'), so in-flight window counts carry over with zero behavior change (still 10/hour/IP per DEC-014). checkAndIncrementRateLimit, rateLimitKey and RateLimitResult are deleted from src/lib/submit-core.ts (call sites updated, tests moved), and rate-limit.ts's 'frozen legacy' header note is removed. This supersedes DEC-038's freeze clause only.
