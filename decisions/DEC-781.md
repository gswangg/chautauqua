# DEC-781: Call for papers is a read-only summary with one drill-in

docs/design/Chautauqua Settings.dc.html:78-101 draws Call for papers as three label:value rows -- Public link (with Copy), Closes ("Sun 16 Aug 2026, 23:59 · America/Los_Angeles" plus an uppercase "In 6 days" note), Custom questions ("4 -- format, audience level, notes for reviewers, accessibility needs") -- with a single "Edit the form" action on the section rule. app/src/pages/settings/CallForPapersPanel.tsx is an always-open form of inputs instead. The primitive already exists and is already used by two panels: SummarySection (DEC-728), whose action writes ?section=<key>&edit=1 so the edit view is URL state. Decision: this panel adopts it -- summary by default, the existing intro/open/close/tracks form only under the drill, every existing save endpoint and validation (including DEC-731's close-before-open field error) untouched. Settings reads as a document; editing is a deliberate second step.


## Amendment (wave 1)

`.chq-settings-row` is `display:flex; flex-direction:column` (settings.css:321-327), so every summary row stacks label over value at ~88px pitch and the Settings page measures 3947px against the frame's 2905. A definition list is scanned, not read: the frame's row is one line at ~50px pitch with the value in a second column and any relative meta ("IN 6 DAYS", counts) right-flushed on the same line. Ruling: the row becomes a three-column grid (label | value | meta) with the meta column collapsing when absent, applied once in settings.css so all seven sections inherit it; section actions move onto the eyebrow rule right-flushed (the head row already exists at settings.css:296-309 — it must be used by all seven, not two); and the tracks-and-rooms block spans the full 820 as two ~392 halves with counts right-flushed. Phone stacking stays a media-query concern and is out of scope for this round.
