# DEC-698: A grid row's cells are POSITIONAL: an absent fact renders an EMPTY cell, never a missing one

Verified: .chq-pub-session-row is `grid-template-columns: 126px 1fr auto` (src/routes/public/public.css.ts:88-95) while SessionSchedule returns null for an unscheduled session (src/routes/public/cards.tsx:105). Grid auto-placement then drops the body into the 126px gutter column, which is exactly the user-reported breakage: title, speaker, chips and description wrapping word-per-word down a 90px column on the most public surface in the product. A component that owns a grid cell must always emit that cell; emptiness is a value, not an absence. When a whole column is switched OFF for a surface (the /embed field toggles), the row states that with a modifier class that re-declares the template — the column count and the cell count agree in every configuration, which is the only invariant a test can hold on to.
