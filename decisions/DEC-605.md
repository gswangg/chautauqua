# DEC-605: The version chain is a speaker-visible fact, and a per-version download is authorised by chain membership, not by the id in the URL

CNT-04 requires the version list as speaker-side evidence (CNT-S2 step 6), and the portal shows only the chain head plus a 'Replace file' button, so a re-upload looks like an overwrite from the only side that performed it. Exposing older versions means a second download route, and the only safe authorisation is the same one the head route uses plus a proof that the requested file id walks back to THIS assignment's chain root — an id handed in by a client is never evidence of ownership.
