# DEC-052: Admin SPA route-level code splitting via React.lazy in App.tsx, with hover/focus chunk prefetch

SPEC §7 mandates 'SPA code-split by route; initial bundle < 300 KB gz' and prefetch-on-hover for common paths; App.tsx currently imports every page statically. Convention: page modules KEEP their named exports; App.tsx alone wraps them as React.lazy(() => import('./pages/X').then(m => ({default: m.XPage}))), one Suspense fallback around Routes, and each NavLink's onMouseEnter/onFocus invokes the same import() thunk from a module-level path→thunk map. No default-export churn in page files, no new routing library.
