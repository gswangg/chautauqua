# DEC-246: Contract-mismatch resolution rule for the DEC-239 sweep

DEC-239 mandates route-level contract tests on exact key names for every SPA payload type, but doesn't say which side yields when a sweep finds a mismatch. Rule: the SPA type file (app/src/pages/*/types.ts) is the contract of record — the server route conforms to it — EXCEPT when the SPA type names data the server cannot supply from existing tables, in which case both sides change together in the same commit and the test pins the new shape. This keeps the fix on the side the render-sweep already exercises and prevents two workers 'fixing' opposite sides of the same wire.
