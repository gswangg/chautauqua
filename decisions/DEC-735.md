# DEC-735: A class describes ONE layout behaviour; a suggestion names the room it would fill

Overview's `.chq-overview-row-actions-stacked` is shared between §02 (which needs an inline row) and §04 (which needs a column), so fixing one breaks the other — the same shared-rule mutation that broke phone agenda visibility. Split it: one class per behaviour, named for that behaviour. Related honesty items on the same page: four identical 'Place at 9:00' suggestions are indistinguishable unless the copy names the room ('Place at 9:00 in Room 2B'), which both disambiguates and informs; and a dangling '· min ·' or 'waiting' clause with no value must be computed or removed, never rendered half-empty.
