# DEC-163: Battery-wave structure: one preflight consolidation lane (task-w4-a) precedes six chained gate lanes; the frozen battery sha is the newest code-bearing first-parent main sha after task-w4-a lands; docs-only merges never invalidate it

DEC-162 requires the six-gate battery at one frozen post-merge sha after wave 3 fully lands, but at wave-4 planning time task-w3-a/b/c had zero pushed commits (refs at branch point 088de4b) and task-w3-d was pushed (3faf9ba) but unmerged — a battery issued now would burn on an incomplete sha. Resolution: exactly one code-bearing lane, task-w4-a, is authorized to consolidate: it may git-merge pushed-but-unmerged origin/task-w3-* branches into its own branch, must implement any wave-3 deliverable that never got pushed (per DEC-157/158/159/160/161), and must leave build+test green. The six gate lanes dependOn it and all cite the same frozen sha — the newest code-bearing first-parent main short-sha once w4-a merges — verified to descend from 2dd2f33 (DEC-129/139). Per DEC-069 only a later CODE merge invalidates a cited sha, so the gates' own sequential docs-only verification-log merges (and scribe commits) do not.
