The API contract is exercised by the walkthrough and API tests, so the SPA conforms to the wire, not vice versa: app/src/pages/review types and pages use the wire names, mapping filters?.trackIds ?? [] into the editor draft and sending {openDate, closeDate, filters, maxEvaluations} on save. Reasserting the F.2 lesson as a binding rule: component render-test mocks MUST mirror the real endpoint wire shape (including null filters), never the SPA's internal draft shape — that divergence is exactly how this crash passed 1308 tests.
