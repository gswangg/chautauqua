# DEC-999: A public agenda block is a content-sized box in its own lane; the day grid neither clips a block nor lets one lane overrun another

The EMB grader and the user report the same defect from opposite ends — "short sessions show only time + track chips, title/speakers cut off" and "overflowing text in calendar grid" — on anon /e/:slug/agenda at 1280x800. The markup explains both: .chq-pub-agenda-block carries NO base rule in PUBLIC_CSS (only two overflow-wrap declarations on its children), and its lane geometry is written inline at src/routes/public/agenda.tsx:110-113 as `width:calc(100/laneCount% - 4px); margin-left:calc((100/laneCount)*lane% + 2px); position:relative`, where a percentage margin on a grid ITEM resolves against the grid area's inline size and stacks with position:relative rather than composing with it. DEC-991 has just reduced KNOWN_CLIP_EXCEPTIONS to one entry, so this route is now inside the DEC-620 clip gate with nowhere to park. The rule: geometry belongs in the stylesheet, not in a template string — the block publishes --chq-lane/--chq-lane-count and one CSS rule owns width and inline-start offset; the block itself is a column flexbox with min-height:0 and no overflow clipping, so the existing minmax(22px, auto) row track grows the spanned track for a 15-minute session instead of the content escaping it. Public content is never truncated to fit a time proportion; the ONE permitted designed truncation in the product remains the admin agenda card's line-clamp on a card that scrolls.

## Amendment (wave 53): an agenda block never stretches its children — the meta is ONE inline row

src/routes/public/public.css.ts:351 defines `.chq-pub-agenda-block` (via `.${ACCENT_BOUND_CLASSES[0]}`) as `display:flex; flex-direction:column` with no `align-items`, so the default `stretch` overrides the `inline-flex` of `.chq-pub-track-chip`/`.chq-pub-format-chip` and every chip rendered at agenda.tsx:143-144 becomes a full-width strip — the gate-4 blocking '622px strips' finding, on a USER-PRIORITY surface. Two-part decision: (a) the block declares `align-items: flex-start`, so a chip is sized by its own content and can never be widened by its container again; (b) the block's time + track + format become ONE `.chq-pub-agenda-block-meta` inline row rather than three stacked flex lines, which is both the frame's anatomy and the reason short blocks read as vertically bloated. A chip is a pill on the session detail already; the block was the only place that contradicted it, so the fix belongs on the container, not on the chip classes (which are shared).
