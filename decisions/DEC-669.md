# DEC-669: Contact headshots reach the Files area as a SEPARATE, separately-paginated tab, never as rows unioned into the deliverable chain query

listEventDeliverableFiles (src/server/repo/files-library.ts:102-135) inner-joins schema.file to schema.submission, and a headshot file carries submissionId null (schema.ts:572-574, linked instead by contact.headshotUrl = '/headshots/<fileId>'), so speaker headshots are structurally invisible in the Files area -- an absence the sbek re-run reported as a real gap. Unioning them into that query would break the rule that a list's items and its total come from ONE where clause (a paged union makes both lie), and would put a row with no session into a table whose every other column is session-shaped. A second scope gets a second tab with its own page envelope, its own endpoint, and its own honest total.
