# DEC-640: An imported participant is a publishable speaker or it is a NAMED skip: it writes the DEC-258 attribution snapshot and an assigned order inside the insert, and an unresolvable reference never creates a stub

DEC-258 makes public/export/ics reads use participant.title_at_time/org_at_time ONLY, with no fallback to the live contact — so an import that leaves them null reproduces EMB-2 (gallery cards with no title/company) on every imported speaker, silently. The field guide's rule stands too: a `position`/`order` column nobody sets is dead, so order is provided-or-max+1 computed INSIDE the insert. And a session or speaker ref that resolves to nothing is a skip that names the ref, never an auto-created placeholder — importing rows the export never contained is worse than reporting the gap.
