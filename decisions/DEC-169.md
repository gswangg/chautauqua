# DEC-169: Form tracks patch validated against the event's tracks

Verified: PATCH /api/v1/forms/:formId accepts any string[] for tracks; since /submit/:slug intersects offered ids with real event tracks and submit-core requires a selection, one typo'd or other-event id silently bricks the public CFP (zero checkboxes, every submit dead-ends). Rule: non-null tracks arrays are deduped preserving order, then every id must be an existing track of the form's event (listTracksForEvent); any unknown/foreign id fails the whole PATCH with the standard {error:{fields:{tracks}}} envelope. null and [] keep their existing offer-all-tracks semantics.
