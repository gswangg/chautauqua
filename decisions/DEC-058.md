# DEC-058: Perf budgets enforced in CI: bundle-check script + Smart Placement config

SPEC §7 sets "initial bundle < 300 KB gz" and says budgets that aren't enforced are decoration, but nothing measures the committed admin bundle. Decide: scripts/bundle-check.ts (Node-side, node:zlib is fine — the DEC-002 pure-core rule governs src/ only) locates the entry chunk public/admin/assets/index-*.js plus the entry index-*.css, gzips them, and throws (fail loudly, nonzero exit) if their combined gzip size exceeds 300 KB; it prints a per-chunk size table either way. Wired as npm run bundle:check and run in the CI build-and-test job immediately after npm run build. Additionally wrangler.jsonc gains "placement": {"mode": "smart"} — SPEC §7 requires Smart Placement on; it is inert under Miniflare, needs no secret, and makes stage 2 pure adapter-swap, so it belongs in stage-1 config.
