# DEC-628: Security middleware coverage is enumerated from the source, not spot-checked

SPEC §6 requires CSRF on every mutating route and rate limits on auth + public submission. Today both hold, but they are held by 90-odd hand-written registrations and three spot tests; a route added without csrfJson is a silent CSRF hole that nothing would catch. Hand-listed manifests desync — enumerate in a test: scan every registration in src/routes/** and fail loudly, naming file:line, when a mutating route carries no CSRF middleware or an unauthenticated write path carries no scoped limit. Deliberate exceptions live in a named allowlist with a stated reason, never as silence.
