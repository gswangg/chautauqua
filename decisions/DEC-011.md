# DEC-011: Zero-dependency RFC 4180 CSV utilities

CSV import (contacts with column mapping, J11) and exports-everywhere (J12) share one hand-rolled module src/lib/csv.ts — parseCsv(text): string[][] handling quoted fields, embedded commas/quotes/newlines, CRLF, and a leading BOM; toCsv(rows: string[][]): string quoting only when needed; plus a header-based column-mapping helper for imports. No npm CSV dependency: the parsing surface is small, auditable, and Workers-safe, and it keeps the bundle inside budget.
