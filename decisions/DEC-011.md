# DEC-011: Zero-dependency RFC 4180 CSV utilities

CSV import (contacts with column mapping, J11) and exports-everywhere (J12) share one hand-rolled module src/lib/csv.ts (moved to src/domain/csv.ts by the wave-65 amendment below) — parseCsv(text): string[][] handling quoted fields, embedded commas/quotes/newlines, CRLF, and a leading BOM; toCsv(rows: string[][]): string quoting only when needed; plus a header-based column-mapping helper for imports. No npm CSV dependency: the parsing surface is small, auditable, and Workers-safe, and it keeps the bundle inside budget.

## Amendment (wave 65): the one CSV module lives in src/domain/csv.ts, because the SPA is a first-class caller

DEC-011 put ONE hand-rolled CSV module at `src/lib/csv.ts` (moved to `src/domain/csv.ts` by this amendment). `app/src/pages/contacts/csv.ts:1-8` then wrote a SECOND parser and serializer, justified verbatim by "the app package builds against its own tsconfig (\"include\": [\"src\"]) and cannot import src/lib/csv.ts across the package boundary" (that module has since moved to `src/domain/csv.ts`). That premise is now FALSE: `app/tsconfig.json:17` includes `../src/domain/**/*.ts`, and `ImportWizard.tsx:14,16` already imports `validateImportMapping` from `src/domain/contacts` and `formatBytes` from `src/domain/files`. DEC-478 set the precedent exactly here when it MOVED `MAX_IMPORT_ROWS` out of a repo module into the domain so the wizard could read the real cap. The two copies are not equivalent: the server throws `CsvParseError` naming the 1-based line where the quote opened (`src/lib/csv.ts:109-114`, moved to `src/domain/csv.ts`), the app throws a bare `Error('Unterminated quoted field in CSV')` with no line — the same file refused two ways, and the wizard's refusal is strictly less actionable. RULING: the module moves to `src/domain/csv.ts` (it is already pure per DEC-002 — no node:/cloudflare imports), `src/lib/csv.ts` is DELETED with every importer repointed and no compatibility re-export, and `mapColumns` is deleted outright if it has no caller left outside its own test.
