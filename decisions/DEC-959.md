# DEC-959: The event hub renders the frame it was drawn from: one action per row, and a published row says what is PUBLISHED

src/routes/root.tsx is measurably off docs/design/Chautauqua Home.dc.html on six counts, and the frame is authoritative. (1) PublishedRow stacks TWO actions (Browse sessions + Speakers) where the frame (line 79) draws exactly one 'Browse sessions' — the hub's whole grammar is one centred action per row. (2) The published row prints shapeLine ('Three tracks · five formats'), but the frame's own sample data distinguishes the three row kinds deliberately: the open-CFP row describes the call's SHAPE (line 432, 'Three tracks · five formats'), the published row describes what is UP (line 440, '12 sessions · full programme up'), the archive row describes SIZE (line 444, '48 sessions · three tracks'). A mock's sample data is spec as surely as its type scale — the build gives two of the three rows the same sentence. (3) The API-docs footer link declares no font-size and inherits the body's, against the frame's 12px/700 (line 104). (4) Body gap is 30px against the frame's 34px (line 38). (5) .chq-home-shell paints --chq-surface (#FAF8F2) where the frame's card is #F4F1E8 = --chq-paper (src/views/theme.ts:31), with a 6px radius and overflow:hidden the build omits; the header's own background then becomes redundant. (6) The page has a <header> but no <main> and no <footer> — the one <h1> DEC-952 requires sits in a bare <div>. Rule: PublishedRow renders ONE action and a publishedLine(publishedSessionCount) meta ('N sessions · full programme up', dropped at zero); the hub's three row kinds keep three distinct meta grammars and none of them borrows another's; the shell is --chq-paper with the frame's radius; the body is <main> and the footer is <footer>; the four pinned numbers are asserted in a test so a fourth gate cannot re-open them.
