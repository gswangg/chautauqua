# DEC-243: Submissions table: Tracks column shows track names, a 'Format' dropdown form field surfaces as a default-visible column, and the Columns picker must be labeled and demonstrably functional

CFP-06 production finding: Tracks renders item.trackIds.length (SubmissionsTable.tsx:245), there is no Format column, and the picker reads as unlabeled do-nothing checkboxes. Design: the Tracks cell maps trackIds through the already-loaded tracks list to names; if the event's CFP form has a dropdown field whose label is 'Format' (case-insensitive), it is toggled visible by default so the table matches the producer's mental model without schema changes (format stays a form answer per DEC-016 — no new submission column); the Columns picker gets a labeled group (fieldset/legend + per-checkbox labels, which also serves the a11y/automation P3) and a route-level test proves includeAnswers=1 returns answers keyed by form_field_id so toggled columns actually populate from seed data.
