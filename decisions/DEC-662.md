# DEC-662: The onboarding grid's per-cell affordance is CONDITIONAL and QUIET; a progress row names the person, not their inbox; and the roster's create actions live on the page's one action row

app/src/pages/speakers/OnboardingGrid.tsx:403-411 renders a "View response" <button> on EVERY form-kind cell regardless of status, so a 6-speaker x 14-task grid ships dozens of controls whose only outcome on a pending cell is an empty modal -- destroying exactly the scanability a grid exists to provide. The mock's rule is conditional-and-quiet: a completed form cell gets a text link styled like the existing "File" link (:392-401), a pending cell gets nothing. Line :354 and :429 also print row.contact.email in the row meta; the mock's speaker line is "Company - has account" and the email belongs to the contact record (the drawer), not to a row whose job is progress at a glance. Finally app/src/pages/Speakers.tsx stacks RosterPanel's own header band above OnboardingGrid's <h1>, giving the page two headers; the mock has one title row carrying Add speaker / Import CSV / New task / Remind.

## Amendment (wave 55): the speakers roster links to the contacts importer with the event preselected instead of denying that importing exists

DEC-662/DEC-746 correctly put CSV import on the Contacts page -- one importer, one dedupe-on-email path, no second half-featured copy -- and OnboardingGrid.tsx:110 records that ruling as a comment. But an organiser standing on the speakers roster with a spreadsheet of speakers has no affordance at all and no signpost; denying a capability the product has is worse than either shipping or naming it. Ruling: the roster's title-action row gains a plain LINK (not a button, not a second importer) into the contacts import wizard carrying this event, and the wizard preselects that event so the imported batch lands where the organiser was standing. Nothing about the import model, its dedupe rule, or DEC-746's assign-to-all expansion changes -- this is navigation, and the single-importer invariant is what makes it safe.
