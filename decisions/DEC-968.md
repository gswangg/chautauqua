# DEC-968: The public session row is the frame's row: caps meta, no abstract — the abstract belongs to the detail page and to an embed that asks for it

docs/design/'Chautauqua Public and Portal.dc.html':59-74 draws the /e/:slug/sessions row as three cells: a 126px gutter (time 15px/700 over room 12px), a body (title 21px, speaker 14px, then ONE meta line of 11px/700/0.06em uppercase track · dot · format), and the action. src/routes/public/cards.tsx renders the body with bordered track chips plus a format chip and then a full SessionDescription disclosure — a <details>/'Show more' triangle on every row, which is what makes the judge's first logged-out screen a wall of prose instead of a programme. The frame's own class already exists and is DEAD: public.css.ts:148 defines .chq-pub-session-tag (11px/700/caps/muted) and no markup in src/ references it — the same dead-vocabulary failure --chq-sunk was. The description is not deletable outright: ?fields=description is part of the embed contract (DEC-289/673) and the rubric exercises field selection. Rule: the sessions list row renders the frame's meta line through .chq-pub-session-tag (track names, a bounded dot separator, then format) and renders NO description by default; src/lib/card-fields.ts gains a sessions-list default (all six fields minus description) that both /e/:slug/sessions and /embed/:slug/sessions use when no ?fields= is given, while an explicit ?fields=…,description restores it byte-identically; TrackChips/FormatChip and their colour-swatch treatment (DEC-430) stay exactly as they are on the agenda blocks and the session detail page, which is where the abstract also stays (detail.tsx:115, unchanged).
