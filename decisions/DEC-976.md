# DEC-976: The app's CSS contract gains its second direction: a chq-* class in the SPA's markup must have a rule

DEC-937's css-contract.scan.test.ts proves two things about app/src CSS — a bare var(--chq-…) resolves, and a button face declares its own font-family — and both are one-directional checks on the STYLESHEET. Nothing checks the markup side, which is where this product has repeatedly lost frames: the participation pill rendered invisible three times because a className resolved to a reset rule, and the public frame's meta grammar sat unbuilt behind .chq-pub-session-tag. DEC-970 is adding exactly this direction for the SSR stylesheets; the admin SPA — 33 routes, the bulk of the surface — has no equivalent, so a renamed or typo'd className there still fails silently at runtime with no build signal. Rule: app/src/css-contract.scan.test.ts gains invariant (C): every chq-* token appearing in a class position in app/src/**/*.tsx (comments stripped, *.test.tsx excluded) has at least one matching class selector in the union of the enumerated app/src/**/*.css files. Both sides ENUMERATE (readdirSync recursive), never hand-list. Violations are FIXED — the missing rule is written, or the dead className is deleted; a class that genuinely carries no style (a pure query/test hook) gets a NAMED exception with its reason beside it in the source, never an open allowlist.

## Amendment (wave 23): a frame citation must quote the line it cites

w21-e's landed criteria rule cites docs/design/Chautauqua Review.dc.html:132/:62 and then declares 150px/70px — the citation looks like evidence and is actually a paraphrase nobody re-read. A LINE NUMBER IS NOT AN IDENTITY, and a citation is not a transcription. RULING: every `docs/design/*.dc.html:<line>` reference in an app/src or src comment must be immediately followed, in the same comment, by the cited line's literal declaration in backticks (e.g. `grid-template-columns:190px 1fr auto`). The quote is the receipt: a reader comparing the rule below to the quote beside it needs no second file open, and a frame edit that moves a line breaks the quote instead of silently rotting the number. The scan asserts quote PRESENCE and that the quoted literal appears verbatim (whitespace-normalised) at that line of that frame file — it deliberately does NOT assert the neighbouring rule equals the quote, because that comparison is the auditor's judgment (a rule may legitimately differ from a frame under a recorded ruling) and because forcing equality would make the scan a rubber stamp.

## Amendment: a task-boundary exclusion in a scan is dated and expires with its wave (wave 2)

app/src/css-contract.scan.test.ts's invariant (D) skips app/src/pages/contacts/** with a comment stating it is 'dated to the current wave's task split, not a standing exemption -- a future wave should re-probe it'. That wave finished long ago; contacts CSS has been unpoliced for dead rules ever since, and the exclusion now reads like policy. Ruling: an exclusion written as temporary is honoured by DELETING it at the next wave that can afford the cleanup, and offenders are resolved by removing the dead rule -- never by adding a className to satisfy the scan, and never by an allowlist populated from the failure output.
