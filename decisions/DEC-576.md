# DEC-576: ONE shell owns chrome geometry: non-scrolling header, flex:1/min-height:0 scrolling body, in-flow phone tab bar; header is a single row with the event as text and the user as initials

The phone tab bar is position:fixed and .chq-main compensates with a guessed 84px of bottom padding, which fails on every page family that scrolls its own region or ends in a control (Settings sections, Content files pagination, Submissions detail and form builder all clip). The README's pattern removes the guess: .chq-shell is a flex column, header and tab bar are flex-shrink:0 in-flow regions, .chq-main is flex:1; min-height:0; overflow-y:auto, and content can never sit under the bar because the bar is not over it. ALVAREZ · SIGN OUT" in 11px/700/0.1em uppercase.
