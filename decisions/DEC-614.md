# DEC-614: Layer 2 (their REST API) is named in prose, never shown as a dead control

We have no Sessionboard account, so stage 1 ships Layer 1 (their CSV/XLSX export) as the working path. The panel states plainly, in prose next to the working control, that API-token import is not implemented in this build and that the export path is the supported one. We do not ship a disabled button, a spinner that never resolves, or a simulator behind a full UI — an unlabelled untested integration reads as a lie, while a named absence reads as credibility.
