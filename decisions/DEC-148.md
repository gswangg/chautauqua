# DEC-148: Free-text criterion kind 'text' ({id,label,kind:'text',required?}) — stored in the same scores map as a string, excluded from weighted scoring/aggregates like dropdowns, validated at the route boundary

ABS-03 flags the missing free-text criterion type. Adding kind:'text' to EvaluationCriterionDef mirrors the existing DEC-018 pattern where dropdown criteria are non-numeric and excluded from computeWeightedScore: text answers live in the same scores record (value is the string), so no new table or column is needed. validateEvaluationScores accepts a string (non-empty when required:true, empty allowed otherwise), keeping the no-partial-submission invariant meaningful without forcing prose. UI is a textarea in the Scorecard.
