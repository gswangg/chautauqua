# DEC-619: Scale is a named profile threaded through the seeder, not a second seeder

scripts/perf-seed-lib.ts gains a PerfProfile record and PERF_PROFILES = { default, aie }, and every pure helper takes the profile explicitly. The module-level count constants are deleted and all call sites updated — no compatibility re-exports, no default-argument shims. A second seeder for 'big' data would drift from the first within a wave; one seeder with two profiles cannot. The aie profile's volumes are exactly those in docs/mandates/scale-mandate.md and are asserted by a test, so the profile cannot quietly shrink.

## Amendment (wave 36): the aie profile is MEASURED, not assumed — the scale mandate's functional bars run as one battery (perf:smoke:aie + gate:scale) and overruns are logged findings

docs/mandates/scale-mandate.md is user-mandated and says every functional bar is "measured against the aie profile"; DEC-619 made that profile real and DEC-644's wave-31 amendment deleted DEFAULT_ONLY_CHECK_NAMES precisely so the review subsystem would be measurable there. Nothing has read the result since: the only aie numbers in docs/verification-log.md are task-w27-d's DIAGNOSTIC run at ceda66f2 (onboarding grid adj 995.7ms, files library adj 414.7ms — both also breaching the 150ms raw ceiling) and task-w31-d's branch-local note that reviewer queue and plan results "newly FAIL at aie scale". Both predate the w29/w31/w32 rewrites that closed those rows at the default profile, so the open question — whether an indexed FK and three Promise.all waves hold at 6,000 contacts and 2,500 submissions, or whether the fix only moved the knee — has never been answered at any current sha. `npm run gate:scale` (scripts/walkthrough/stress.ts) already asserts the mandate's own functional bars against that profile and is likewise unrun. RULING: one lane seeds the aie profile once and runs both instruments against it, recording numbers verbatim. Per DEC-331/DEC-347 clause (3) the measuring lane does not optimise src/ — every overrun is a LOGGED FINDING naming the owning module and route, owned by a later wave — and a bar the harness cannot exercise is recorded as such rather than skipped silently.
