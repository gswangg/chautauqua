# DEC-187: Zero-setup dev vars bootstrap: .dev.vars stays untracked; scripts/ensure-dev-vars.ts materializes it from .dev.vars.example; supersedes DEC-183's committed-.dev.vars clause

Operator commit 629d57e ("Security: untrack .dev.vars — a real secret landed in it; commit .dev.vars.example instead") is binding and stands: a tracked live-vars file invited real secrets into history, exactly what happened. But untracking broke stage-1 zero-setup: fresh clones fail npm test (test/wrangler-config.test.ts:54 reads ../.dev.vars) and fail the walkthrough (/dev/mailbox never mounts without DEV_MODE; speaker.ts:401, producer.ts:450, scale.ts:301 assert 200). Fix: (1) new scripts/ensure-dev-vars.ts exporting `ensureDevVars(rootDir: string): "created" | "exists"` — if <rootDir>/.dev.vars exists return "exists" untouched (never overwrite, never read or print its contents — the local copy may hold a real secret); else if .dev.vars.example is missing throw (fail loudly); else copy .dev.vars.example byte-for-byte to .dev.vars and return "created". Runnable directly via tsx (calls ensureDevVars(repo root)). Tagged '// DEC-187'. (2) package.json gains "predev": "tsx scripts/ensure-dev-vars.ts" so `npm run dev` stays zero-setup with the README unchanged. (3) scripts/render-sweep.ts calls ensureDevVars(REPO_ROOT) before spawning wrangler dev; ci.yml's walkthrough and perf-smoke jobs run `npx tsx scripts/ensure-dev-vars.ts` before their 'Start wrangler dev' steps (they use npx wrangler dev, bypassing predev). (4) test/wrangler-config.test.ts retargets its DEV_MODE=1 assertion to .dev.vars.example (tracked), asserts .gitignore keeps a literal '.dev.vars' line so the live file can never be re-tracked, and unit-tests ensureDevVars in a temp dir (creates when absent; never overwrites). DEC-183's production-safety clause (no DEV_MODE in deployable wrangler.jsonc; its comment marker stays) remains in force; only its 'commit .dev.vars' clause is superseded.
