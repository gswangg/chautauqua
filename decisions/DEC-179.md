# DEC-179: CSV formula-injection neutralization in the single toCsv serializer

formatCell in src/lib/csv.ts:138 emits attacker-controlled public-CFP strings (titles, answers, names) verbatim, so cells starting with '=', '+', '-', '@' execute as formulas in Excel/Sheets (CWE-1236) via both organizer exports (src/routes/api/exports.ts:49,77) and review results CSV (src/routes/review.ts:435). Fix once at the choke point: string cells whose first character is '=', '+', '-', '@', tab, or CR are prefixed with a single apostrophe before the existing RFC-4180 quoting rules run. Number and null cells are exempt (negative numbers stay clean; all numeric cells arrive typed as number). Accepted tradeoff: string values like phone numbers beginning '+' gain a leading apostrophe in spreadsheet imports — safety beats cosmetics for organizer-opened files.
