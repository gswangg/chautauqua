J9 is warn-never-block, but app/src/pages/agenda/DayGrid.tsx:140 turns a cell into a Place button only `if (armed && !isOccupied(...))` — via the accessible path an organizer literally cannot create a clash, and the only way in is clicking an already-placed card (line 98-104), whose accessible name says nothing about what the click will do. N is counted, never assumed to be one: assignLanes already lays out N lanes, so the count in the caption is the same N the layout uses — the conflict copy stops saying "pair" and starts saying how many.
