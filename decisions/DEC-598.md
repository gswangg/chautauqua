# DEC-598: A submission's tracks and session format are organiser-editable through the same join writer the portal edit uses

Tracks can only ever be set by the public CFP form or a speaker's portal edit: PATCH /api/v1/submissions/:id accepts title and description only, and the quick New-submission modal collects neither track nor format. A submission created in the admin is therefore permanently track-less, which silently removes it from track-scoped reviewer assignment, from the public track filter, and from any track-coloured agenda reasoning. PATCH takes an optional trackIds array as a full-set replace routed through the same submission_track writer portal-edit uses (two functions claiming the same semantics end in the same helper), and the quick-create modal collects tracks as multi-select per DEC-579 plus the DEC-592 format field.
