# DEC-153: Calendar-date display rule: date-only values (stored as UTC-midnight ms by dateInputToMs) render via new null-safe formatDateOnly() using UTC date components; formatDate stays local-tz for true instants

The task due-date off-by-one (enter 5/25, see 5/24) is new Date(utcMidnightMs).toLocaleDateString() shifting the calendar date in western timezones. Since every date-only field is written as T00:00:00.000Z, displaying with timeZone:'UTC' makes the entered date round-trip exactly — the mandate's intent — without per-event tz plumbing in the SPA. The helper joins DEC-146's null-safe family in app/src/lib/dates.ts ('—' for null/NaN). Portal SSR already slices ISO strings (UTC) and is correct; only local-tz formatting of calendar dates is banned.
