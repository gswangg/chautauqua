# DEC-045: Admin submission detail at /admin/submissions/:id, consuming existing endpoints only

J3 triage needs a producer-readable single-submission view (full answers, participants, tracks, status control, clone). The existing GET /api/v1/submissions/:id (SubmissionDetail in src/server/repo/submissions.ts) plus the forms and tracks endpoints already carry everything, so this is SPA-only: a React Router route /submissions/:id under the /admin basename, linked from the submissions table title cell. Status changes reuse the existing bulk endpoint with ids:[id] (optimistic, loud rollback). The duplicate app/src/pages/submissions/useCurrentEventId.ts is deleted in favor of app/src/lib/useCurrentEvent.ts (DEC-024's canon).
