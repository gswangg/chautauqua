# DEC-063: SPEC §9 persona walkthroughs are CI-enforced: a third 'walkthrough' job boots seeded wrangler dev and runs `npm run walkthrough`

SPEC §7's own language — budgets that aren't enforced are decoration — applies equally to §9's acceptance bar. The walkthrough job mirrors the existing perf-smoke job shape exactly (npm ci, db:migrate, seed, background `npx wrangler dev --port 8787`, poll /health for 60s, run the check, dump wrangler-dev.log on failure) minus perf:seed, so every push re-walks J1->J12 as all five personas against the standard seed. package.json gains a single `walkthrough` script (`tsx scripts/walkthrough.ts`, default --url http://localhost:8787) so evaluators can run the same gate locally with one command documented in README.
