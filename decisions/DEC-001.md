# DEC-001: Single-package repo layout, toolchain, and bindings

One npm package, no workspaces — one deployable Worker per SPEC §4. Layout: src/ = Worker code (Hono), app/ = admin React SPA (own Vite root + tsconfig, builds to public/admin/), migrations/ = D1 SQL generated by drizzle-kit, scripts/ = seed tooling, test/ = vitest unit tests, public/ = Worker static assets dir. Dependencies (canonical set, so parallel workers add identical entries): hono, drizzle-orm; dev: drizzle-kit, wrangler (v4), @cloudflare/workers-types, react, react-dom, react-router-dom, vite, @vitejs/plugin-react, vitest, typescript, tsx. Wrangler config is wrangler.jsonc: D1 binding DB (database_name chautauqua, migrations_dir migrations), R2 binding FILES (bucket chautauqua-files), KV binding KV, cron trigger */15 * * * *, assets served from public/, compatibility flag nodejs_compat off (pure Web APIs only). npm scripts: dev=wrangler dev, dev:app=vite build --watch in app/, build=tsc --noEmit + vite build, db:generate=drizzle-kit generate, db:migrate=wrangler d1 migrations apply chautauqua --local, seed=tsx scripts/seed.ts then wrangler d1 execute chautauqua --local --file=.seed.sql, test=vitest run. Stage-1 rule: zero secrets; .dev.vars not required to run.
