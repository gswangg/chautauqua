# DEC-056: Public API docs page at GET /docs/api (hand-maintained SSR)

SPEC §10.6 plus the §3 own-your-data pitch: the technical teammate persona needs to see the API surface without reading source. A no-login Hono JSX SSR page in a new src/routes/docs.tsx (sub-app, mounted only in src/index.ts per DEC-012) documents: bearer auth (Authorization: Bearer chq_…, minted at Admin → Settings → API tokens, cookie sessions also accepted), the DEC-013 error {error:{code,message,fields?}} and list {items,total,page,perPage} envelopes, and a hand-maintained method/path/role table of the main /api/v1 resource groups (events, forms, submissions, review, tasks, comms, agenda, contacts, exports, tokens). Hand-maintained beats runtime introspection for architectural simplicity; it documents no secrets so it is public. Linked from the SSR landing page and the README evaluator table.
