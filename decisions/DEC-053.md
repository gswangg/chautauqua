# DEC-053: J1→J12 walkthrough harness: scripts/walkthrough.ts against a running dev URL

SPEC §9's real bar is persona walkthroughs, and stage 1 needs a repeatable, zero-secret way to run them. scripts/walkthrough.ts (npm run walkthrough, --url flag defaulting to http://localhost:8787, tsx like perf-smoke) walks J1→J12 as producer/speaker/reviewer/public against a migrated+seeded dev server. Auth contract: GET /login captures the chq_csrf cookie, POST /login is form-encoded with the hidden field named after the cookie, session cookie carried in a cookie jar; JSON mutations send header 'x-chq-csrf: 1'. It creates throwaway records under a unique wk-<epoch> event slug for J1/J2 and uses the seeded devflow-conf-2027 personas for the rest; assertions are status codes + key JSON fields; first failure prints status+body and exits non-zero (fail loudly). Pure helpers live in scripts/walkthrough-lib.ts and are vitest-covered.
