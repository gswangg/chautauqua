# DEC-617: The hardened embed element is one file its own test executes, and it fails visible

public/embed.js is plain JS served as a static asset from our own origin and defines <chq-embed>. Its rules live only there — src must be same-origin as the script's own origin; the iframe is sandboxed; a resize message counts only when event.origin, event.source AND the instance id all match; height is clamped to [160, 4000] — and the test loads that same file and runs it, so there is no TypeScript copy of the rules to drift out of sync. Any rejection renders a visible link to the surface, never a blank box. The plain iframe snippet stays the default; the element is the upgrade, not a replacement. This is the one piece of our code that runs on somebody else's page, so it validates every axis rather than trusting any of them.
