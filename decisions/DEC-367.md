The SPA (Vite-bundled CSS) and the SSR surfaces (inline <style> strings) must not drift, so both declare the SAME --chq-* custom-property names with the handoff's exact values. Colour: --chq-paper #F4F1E8, --chq-surface #FAF8F2, --chq-surface-sunk #EFEBDF, --chq-ink #1B1D17, --chq-ink-2 #3F4237, --chq-muted #565A4B, --chq-disabled #8E8A7A, --chq-hairline #E1DDCE, --chq-rule #D3CFC0, --chq-border #BAB6A6, --chq-border-strong #CFC7B7, --chq-brand #4E5C31, --chq-brand-hover #3C471F, --chq-on-brand #F7F9F0; on ink: --chq-on-ink #F4F1E8, --chq-on-ink-muted #B5AFA2, --chq-on-ink-hairline #3A3D32. Type: --chq-font-display 'Familjen Grotesk', --chq-font-ui 'Figtree', both self-hosted from the already-vendored /fonts/FamiljenGrotesk-var.woff2 and /fonts/Figtree-var.woff2 via @font-face with format('woff2-variations') and weight RANGES (400 700 / 400 800) per public/fonts/README.md — no fonts.googleapis.com request from the Worker. Radius --chq-r-ctl 4px (6px phone), --chq-r-card 5px, --chq-r-pill 99px. THERE IS NO RED AND NO THIRD ACCENT: lateness, clashes and 'not reviewed' are set in type (10-11px / weight 800 / letter-spacing .09-.11em / uppercase / Ink) via the shared .chq-flag class — the existing #c0392b error banner and #fdecea conflict chip colours are removed, not recoloured. Floors that every lane must hold: 10px type minimum, 44px minimum interactive height at phone width, WCAG AA (muted floor #565A4B on paper, #B5AFA2 on ink), no shadows inside the UI (the mocks' frame shadows are canvas presentation), nav underline via box-shadow: inset 0 -2px 0 var(--chq-brand) never border-bottom. No CSS framework and no new npm dependency.
