# DEC-132: Public submit ignores rule-hidden file fields entirely: no upload validation error, no R2 put, no file row, no answer row

validateAnswers (src/forms/validate.ts:40-43) strips rule-hidden fields from `cleaned`, but src/routes/public/submit.tsx's file handling runs before/after it without a visibility check: an invalid file on a hidden field 400s the whole submit, and a valid one is stored in R2 and re-added via cleaned[field.id] = fileId (line 484) — bypassing the server-side conditional-visibility enforcement SPEC §6/DEC-008 requires. Fix in two guards: (a) in the file-validation loop, skip fields where isVisible(field, answers) is false — no validateUpload, no fileErrors entry, no 'pending' placeholder; (b) in the post-create upload loop, only upload/insert/replace when cleaned[field.id] === 'pending' (the placeholder validateAnswers preserved for visible, valid file fields). Hidden file fields thus leave zero trace: no R2 object, no file row, no submission_answer.
