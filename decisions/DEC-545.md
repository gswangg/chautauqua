# DEC-545: The admin SPA has ONE date-time formatter, in app/src/lib/dates.ts, and the ban on page-level toLocale* is enforced by a globbed scan rather than by a comment

DEC-146's module docblock (app/src/lib/dates.ts:1-6) states the rule plainly: "Pages must never call new Date(x).toISOString()/toLocale* directly on a nullable/unvalidated value -- go through these helpers so a null/undefined/NaN timestamp renders as an empty input or em dash instead of crashing the SPA". The module then ships formatDate (date-only) and formatDateOnly (UTC calendar-date labels, DEC-153) and no date-TIME formatter at all -- so seven pages rolled their own: app/src/pages/content/format.ts:15, settings/ApiTokensPanel.tsx:15, contacts/PipelineBoard.tsx:385, contacts/ContactDrawer.tsx:348, submissions/SubmissionsTable.tsx:27, submissions/SubmissionDetailPage.tsx:24 and comms/HistoryTab.tsx:6. Each is `new Date(ms).toLocale*()` with no null guard, so a null sentAt/lastUsedAt renders the literal string "Invalid Date" to a producer instead of DEC-146's em dash, and the rule that was supposed to prevent exactly this is a comment nobody can violate loudly. This is the DEC-538 lesson (a hand-copied vocabulary drifts) and the DEC-539 lesson (guard the guards) applied to the SPA. Decision: (a) app/src/lib/dates.ts gains `formatDateTime(ms: number | null | undefined): string` -- null/undefined/NaN/invalid render '—', otherwise the viewer's locale date+time, matching what the seven copies do today. (b) It also gains `formatDateTimeInZone(value: number | string, timeZone: string): string` so app/src/pages/comms/icsChip.ts:17 -- the one call that is CORRECT to be zone-explicit, per DEC-494's owning-event rule -- stops being an unexplained exception and becomes a named one. (c) Every one of the seven sites is routed to the helper whose SEMANTIC it already uses: formatDate where it was toLocaleDateString on an instant, formatDateOnly where the value is a DEC-153 UTC-midnight label, formatDateTime otherwise. This is a single-sourcing refactor, not a semantics change -- no site may switch classes. (d) A globbed source scan under test/ asserts no file in app/src outside app/src/lib/dates.ts and outside *.test.* calls toLocaleString/toLocaleDateString/toLocaleTimeString, so the eighth copy cannot land.
