# DEC-597: Contacts are creatable and exportable from the directory itself; contacts becomes a first-class export kind

POST /contacts exists but the directory offers only Import CSV — there is no way to add one person, and no way to get the list back out, on a screen whose whole purpose is the org's people. Adding a client-side CSV built from the loaded page would export whatever happened to be paginated in, which is precisely the cap-the-UI-cannot-see failure; so 'contacts' joins EXPORT_KINDS and inherits DEC-560's deterministic ordering and DEC-027's export route, and the New-contact modal writes through the endpoint that already exists.
