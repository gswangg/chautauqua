# DEC-738: Labels ARE customFields minus the reserved travel key, formatted once server-side as `key value` chips in stable key order

DEC-726 settled that a contact's Labels render customFields ("role speaker · year 2027") and retired DEC-712's derived participation roles, but the code still ships DEC-712: src/routes/api/contacts/crud.ts calls repo.fetchContactLabels over `participant`. Two details DEC-726 left open, decided here so directory, drawer and merge cannot drift: (1) `travel_logistics` (customFields.TRAVEL_KEY) is NOT a label — it is prose with its own labelled field, and as a chip it would blow out every row; (2) the format is computed ONCE, server-side, as `${key} ${value}` per entry in stable key order, so the list payload, the drawer and any future consumer render the identical string instead of three formatters. The derived-role query and its repo helper are deleted, not kept behind a flag.
