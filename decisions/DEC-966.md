# DEC-966: The seeded call for papers is the frame's question table — eight questions, three of them optional, each with the hint the frame gives it

docs/design/ pins the seeded form twice, identically and at field granularity: 'Chautauqua Submissions.dc.html':548-555 (label · hint · type · required) and 'Chautauqua Settings.dc.html':679-688, corroborated by the Settings read-view sentence '4 — format, audience level, notes for reviewers, accessibility needs' (:99) and the data-figures line '8 CFP questions (3 built-in + Track + 4 custom)' (README:365). scripts/seed.ts:438-450 seeds three custom questions, not four: 'Accessibility needs' (short text, optional, hint 'Passed to the venue team only') does not exist, so the frame's FORM ANSWERS row, the builder's eighth row, the portal profile row ('Chautauqua Public and Portal.dc.html':533, 789) and the task-response row ('Chautauqua Speakers.dc.html':374) all render against data that was never seeded. Two seeded rows also contradict the frame outright: Audience level is required:true where both frames mark it Optional, and the labels/hints drift ('Description' for the frame's 'Abstract', 'Session format' for 'Format', 'Optional context for the program committee.' for 'Never shown publicly'). Rule: the seeded default form matches the frame's table in label, help text, required flag and order, and gains the accessibility question (id 'field_accessibility_needs', kind text, section session, required false, positioned after notes-for-reviewers); a hint that states a NUMBER is derived from the seeded data it describes (the format hint counts the seeded options, the abstract hint states the enforced MAX_LONG_TEXT_LENGTH) rather than copied as a literal that can lie; a test asserts the seeded set by id with its exact required flags so a fourth wave cannot quietly re-require a field. REFUSED, with reason: the frame's builder mock omits job_title/company/bio, but DEC-321 added them deliberately so the public speakers directory and gallery have a title/company to show (EMB-12) — they stay, optional, and this decision records the refusal so it is not re-litigated.
