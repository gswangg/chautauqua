# DEC-885: The public speaker directory is three-up at the desktop frame, an absent headshot is a DRAWN placeholder, and every day pill says whether it is the day being shown

src/routes/public/public.css.ts:176 sets the speaker grid to repeat(auto-fill, minmax(140px,1fr)) — a phone rule that never stops applying, so it packs seven columns at the 1240-1440 desktop frame against the frame's three. Desktop columns are COUNTED, not inferred from a floor: a min-width:900px rule sets repeat(3, 1fr) and the existing narrow rules stay untouched (additive reflow, desktop-only scope). The gallery keeps its own tighter .chq-pub-gallery-grid modifier and is not changed. An absent headshot currently renders .chq-pub-headshot-fallback as an empty sunk box, which reads as a broken image; it becomes a deliberate drawn placeholder — a repeating-linear-gradient hatch in the hairline token with the speaker's initials centered — so an absence looks chosen. And the public /agenda day navigation must emit ?day= links on the DEFAULT view (not #anchors) and mark the day in view with aria-current="page" plus the active pill treatment on both the default and the parameterized view: a navigation control that never says where you are is a list of links.

## Amendment (findings wave 9): ONE drawn headshot placeholder, one rendering — every headshot-less surface draws the initials, and its size is CSS-owned

DEC-885 ruled that an absent headshot is a drawn placeholder (hatch + the speaker's initials) rather than an empty sunk box that reads as a broken image. src/routes/public/speakers.tsx:128-130 honours that. src/routes/public/detail.tsx:49 does not: the speaker DETAIL page — the drill-in EMB-13 grades, and the one page where a reader is looking hardest at that person — renders `<div class="chq-pub-headshot-fallback" style="width:160px" />` with no children at all, i.e. exactly the empty box the decision exists to forbid, sized by an inline style that bypasses the CSS that owns every other instance. The initials helper (speakerInitials) is already exported from cards.tsx for precisely this reason. Ruling: the fallback renders initials on every surface without exception, aria-hidden where an accessible name already sits beside it, and its box size is a class in the public CSS family, never an inline style — a placeholder whose geometry lives at the call site is a placeholder nobody owns. Same file, same register: an affiliation line built from title+company must not render an empty `<p>` when a speaker has neither, because a blank line the reader cannot explain is worse than no line.
