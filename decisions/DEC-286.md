# DEC-286: Wave-8 section->lane map: mandatory -c2- log infix, one new file per lane, and a disjoint port assignment with the fresh-clone lane owning default 8787

Two collisions are already committed and would silently destroy evidence. First, campaign 1 committed docs/verification-log/task-w8-a-walkthrough.md, task-w8-b-build-test.md, task-w8-d-perf-smoke.md, task-w8-d-triage-closure.md, task-w8-e-render-sweep.md, task-w8-f-spec-audit.md and task-w8-g-triage-closure.md — six of eight wave-8 lane letters already have a homonym file, and a lane writing the bare name would OVERWRITE a first-campaign log rather than add to it (DEC-129's homonym guard only protects the grep, not the filename). Every wave-8 log is therefore docs/verification-log/task-w8-<x>-c2-<scope>.md, the '-c2-' infix mandatory exactly as DEC-264 required for wave 4. Second, four sections need a live wrangler dev simultaneously, and DEC-257 requires the fresh-clone lane to run README-verbatim on the DEFAULT port with no --var override; so ports are assigned disjointly by the planner rather than chosen by lanes: b=8791, c=8792, d=8793, f=8794 (only if it needs a server), g=8787 default and exclusively, a/e/h take no port. The section->letter map is fixed here so two lanes never claim the same scope: a build+test, b walkthrough, c perf-smoke, d render-sweep, e spec-audit, f triage-closure, g fresh-clone, h rubric-coverage. Every lane commits exactly one new file on its own branch and touches nothing under src/, app/, test/, scripts/, migrations/, decisions/, field-guide/ or docs/eval-findings.md, and never edits another lane's log (DEC-256 para 4, DEC-259).
