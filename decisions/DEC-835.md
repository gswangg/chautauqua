# DEC-835: A public day pill is a navigation, not a scroll — every public day view names its day in the URL

VERIFIED DaySwitcher (src/routes/public/agenda.tsx:294-296) emits '#chq-day-<day>' for any day rendered on the current page and only falls back to '?day=' for days that are not, so the DEFAULT /agenda and /schedule views hand a visitor in-page anchors: the day being read is not in the URL, cannot be linked or shared, and the same control behaves as two different things depending on which view you arrived from. Decision: the pill always emits '?day=<day>' (carrying trackId/q forward exactly as DEC-783 established) on every view, with aria-current marking the active day — one control, one grammar, and the day a visitor is reading is always addressable. The in-page anchor ids stay for deep links that already exist.
