# DEC-593: The gallery is the speakers directory's photo-led twin: same person fields, one card, differing only in layout

EMB-12 requires gallery cards to carry headshot, name, job title and company and to degrade gracefully for a speaker with no photo; today GalleryContent renders a bare tile with an image or nothing at all and captions itself 'Headshots only, no session details', which is copy written against the code rather than the spec. SpeakersContent already renders the exact same fields correctly. Two renderings of one person must not disagree about which facts a person has: extract one speaker-card component, give the fallback tile the same treatment the directory uses, and let the two surfaces differ only in grid shape and in whether the session sublist is shown.
