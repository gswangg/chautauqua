# DEC-896: A settings row is label / value / hint, and the rail names the section actually in view

Six panels render through this one primitive, so the frame's structural complaint against all six is ONE change here, not six per-panel rewrites -- one shared vocabulary beats per-page fixes. Rule: SummarySectionRow gains an optional `hint: ReactNode` rendered as the row's third grid column, collapsing when absent (never an empty cell); at least three panels supply real hints in the same change, because a prop with one call site is a setting nobody sets; and the rail's active state follows the section in view via IntersectionObserver, with an explicit rail click winning until the next scroll settles.
